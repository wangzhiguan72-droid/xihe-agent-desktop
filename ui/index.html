设置

外观与启动

外观与动画开关即时生效并自动记住；动画中可跳过，按 Esc 也可进入。

模型推理档位
独立于顶部的工作模式。每个模型共用五档滑杆；滑杆会映射到该模型和接口已验证的稳定档位。思考预算与原生强度分别标注。主对话、子代理、追问、识图和压缩均使用对应模型设置。更改后点击弹窗底部「保存」才会生效；取消会丢弃本次设置。若同时修改了接口格式，请先保存，重新打开设置后再选择更新后的档位。测试按钮会发送真实短请求并计入用量；接口接受不代表中转实际执行。
模型提供商（Base URL / 接口格式 / 模型名 / Key）
接口格式分别选择 Anthropic Messages、Chat Completions 或 Responses；三者的请求结构不同，不能只改地址后缀。Base URL 可填中转基础地址（如 https://example.com/v1）；系统会避免重复拼接路径。当前 OpenAI 官方 GPT5/6 沿用自动 Responses 适配。模型可添加、编辑、测试、停用或删除；「查询当前 Key 可见模型」只读目录，不产生模型生成用量。网站总目录存在型号，不代表当前密钥所属账户组可调用。
内置 7 家不够用就点下面的「＋ 添加供应商」——可以无限加（自建网关、公司内网端点、新的中转站都行）。自定义供应商要填一个标识 id（小写字母数字_-，模型路由靠它），Key 存到 config/custom_<id>.key。
角色模型（建模 / 编程 / 论文 / 审查）
留空 = 跟随当前会话或默认模型。数学建模主会话默认使用建模手；动态子代理按任务自动选择。可填模型名或 provider:model，手动在顶部选择的会话模型始终优先。
判断层（Jev / 有限选项复核）
只复核 3 个候选方案，不参与建模和论文生成。默认策略是“与主模型一致且置信度达到门槛才记为通过”；分歧或低置信度只升级，不自动改选。密钥仍由上面的供应商配置管理。
技能首检质检（首次使用验收）
打开后，每个技能首次使用时用 LLM 审一遍正文：前后矛盾、与羲和门禁冲突、含糊指令、数模写作指导缺陷，结论附在加载结果里。同指纹永久跳过重检；内容变化自动重新首检；质检失败不阻塞加载。修复副本只在你确认后生成，共享技能原件一律不动。
