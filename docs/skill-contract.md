# Skill 适用性声明

在 Skill 目录中加入 `skill-contract.json`。该文件随完整包指纹、导入导出和会话快照一起冻结。修改声明就是新版本内容；旧会话继续使用原声明。缺少声明的旧 Skill 保持可用，显示适配性待确认。

```json
{
  "schema_version": 1,
  "slots": ["research"],
  "modes": ["append", "replace"],
  "problem_types": ["time-series"],
  "stages": ["solving", "validation"],
  "requires": {"data": ["time-series"], "tools": ["python_run"], "plugins": []},
  "conflicts": ["another-method"],
  "constraints": {"split": "chronological"}
}
```

除 `schema_version` 外均可省略。省略范围表示通用声明；非空范围列出支持的标识符。`contest_kinds` 可限制赛事。只允许已知字段；无效声明不能作为可安装包导入。工具依赖检查宿主注册的工具名；插件依赖检查实际加载的插件 ID。工具注册不证明凭据、库环境或远程服务健康。

`constraints` 只登记当前方法确实不能违反的适用条件或接口约定。历史算例中的节点数、求解器容差和步长应写成方法建议，不因数值不同直接判不适配。PDE Skill 1.1.0 已解除这类历史参数限制；算法和局部步骤由模型根据本题选择，题目事实、当届规则及结果证据继续核实。

项目方案增加 `task_context`：`problem_types`、`stages`、`data` 是数组或 null，`constraints` 是字符串映射。null/省略表示未知，空数组表示已明确没有对应条件。信息由用户登记，不按标题猜测，不把方法模板的推荐自动写成任务事实。多题型任务须全部在声明范围内，否则应缩小当前任务范围。参数使用精确字符串比较，不自动推断单位或数值等价。

明确错题型、错阶段、错槽位、缺数据/工具/插件、固定参数不同，均不注入该 Skill。先尝试用户配置的回退；仍不适配时保留包、指纹和失败原因。任一方向声明互斥或两个 Skill 固定参数相冲突时，同时停止注入两者。主代理、按角色组合的子代理和动态 `skill_load` 都经过检查。未知项展示待确认并在组合提示中要求核对；此版本不自动理解 Markdown 中未声明的冲突。

动态读取冻结选择时沿用原槽位；额外 Skill 默认作为 `research` / `append`，可显式传入 `slot` 和 `mode`，仍需通过检查。会话记录已动态加载的版本和组合，后续读取不能绕过互斥检查，也不能静默切换同名版本。没有方案快照的旧会话按未知任务条件检查槽位、依赖和动态组合；原有历史正文不会被自动重写。未知的首选 Skill 保留用户选择，不因缺声明自动换成通用 Skill。

安装完整性、声明条件匹配和增益证据独立展示。模板的可用性只表示安装条件；所有当前默认/自定义组合均没有已认证的真实增益。可信宿主可通过 `skill_gain.run` 做固定条件的配对实验，接口及证据边界见 `skill-gain-evidence.md`。普通方案 JSON、导入包和 HTTP 请求不能签发可信增益。

项目方案弹窗可编辑条件后点“检查草稿适配性”，不保存、不修改当前会话。保存后用于新会话。已有会话继续使用原版本和原条件；调整当前任务条件应保存方案并开启新会话。
