# 将 MCMsource 的图形表达迁移到其他比赛

2026-11-15。用户目标是借鉴绘图方法用于其他比赛；本轮仅作本地演练，不要求美赛题面或正式盲评。

## 实际来源

## 在羲和使用

打开“项目方案”，在**图表方法**选择 `xihe-evidence-figures`，设为“替换”或“补充”，保存后创建新会话。已有会话继续使用冻结版本。它不把国赛切成美赛，不改变赛事规则，也不替换你的研究方法。可同时选用自己的预测、优化或机理 Skill。

也可以在界面按同样的槽位与开关手工组合一份演示方案；实际项目保留/选择自己的赛事与方法。不要用演示配置覆盖未导出的个人草稿。

## 迁移的内容

- 从图要回答的问题选择图型，不按美赛模板凑图或强制每问一图。
- 数据图、机制示意图、地图分开登记证据来源；没有模拟数据不画实测热图，没有空间数据不画伪地理关系。
- 同口径方案对照共用单位、尺度、图例和区域。目标不同的答案分面叙述，不称为同口径改进。
- 敏感性曲线使用真实重算点，标明固定条件，不凭单次运行生成置信带。
- 精确数字适合表格；全篇图序从对象、模型、结果到边界逐步展开。

自带小脚本支持柱图、成对点图和参数曲线，导出可编辑矢量 PDF、PNG 及字段/哈希清单。复杂地图、网络图和其他图型仍由当前环境的合适工具完成，不因脚本功能少就改造题目。

演练产出的图件、来源清单与验收记录属于本机运行产物，不随包分发。来源清单接入正式运行回执和摘要/图件追溯，修改图件时旧引用失效。缺值、字符串数字、非有限值、不同单位共用尺度等情形会拒绝作图。
