# 国赛与妈妈杯分开的工作流

依据：当届官方格式与 AI 使用规范、公开赛事复盘材料及实际复算记录。历史结果用于暴露故障，不作为新项目答案；使用前重新核对当届文件。

| 项目 | 国赛 CUMCM | 妈妈杯大数据竞赛 |
|---|---|---|
| 主技能 | my-cumcm 的现有宿主入口 | my-mathorcup-bigdata，跨宿主自包含 |
| 论文骨架 | templates/cumcm_paper | templates/mathorcup_bigdata_paper |
| 流程 | 现有基线—假设迭代—冻结—交付 | 规则档—数据可解性—逐问基线—跨问交接—改进—独立复算—交付准备 |
| 赛时 | 已有时钟规则，74小时仅参考 | 实际截止/剩余时间；不按国赛比例自动切阶段 |
| 格式依据 | 当届官方规则与明确的本机质量契约分列 | 2026初赛：第二页目录、正文从1编号≤30页，附录不限且全源码；其他届次重新核 |
| 支撑包 | 保留本机默认严格<20MB，可用有来源规则覆盖 | 不继承20MB；明确平台或当届上限时登记 |
| AI与人类职责 | 按当届规定 | 本届声明在参考文献后；详情草稿/队员采纳修改/独立核心工作/签署分开 |

羲和“开始比赛”可选择赛事；默认按项目标题识别，含糊的 MathorCup 名称不自动等于大数据竞赛。提供商改变时妈妈杯主技能不变。妈妈杯技能缺失会显示失败而不会加载国赛变体。已有会话按标题识别，实际技能以界面返回为准。

先读规则，用 `contest_rules` 登记条款，再编译。规则变化作废论文审计；`final` 要重查当前论文、支撑包和已登记复算。`independent_verify` 读取机器JSON清单，核源结果/复算实际数值及论文/文件哈希；声明独立和退出0不能证明模型正确或真正隔离。接口见技能 references/verification-manifest.md。

妈妈杯规则必须明确 `profile=mathorcup-bigdata-年份-preliminary|final`，2026初赛使用已核验档，不能登记成999页或取消完整源码/AI声明来降低门禁。届次不是项目创建日期，真实来源仍需回读。用户补充的博主摘要和七张截图拆为“第三方主张取舍”和“预处理与图形”参考：数字只作待核线索，MICE/3σ/删缺失均须适用条件；MCMsource只借鉴美赛图件组织。含答案参考与聊天不交盲算者。

极致模式修复：实际继承 deep 全规则；失败子任务由主控接管，不因“总师不亲算”停工；Q2/Q3已有证据不因Q4失败重做；复算/评审/编译/人工确认分状态，模型通道不静默替换。文件名列表不能冒充附录源码，修改科学结果重算下游，仅排版修复不盲重跑。

技术 `final` 表示登记的技术门禁通过，不等于已满足队员独立核心工作/人工审核/签署或已提交。妈妈杯自动AI详情明确为草稿待补关键交互和人工采纳记录。旧题35.42与22.82差35.57%（以35.42为分母），不能称落在±35%；不同体积定义须分列。复算范围与分歧清单分别列出，不把另行Q4比较混入Q2/Q3的八项分歧。

验证入口：`npm run test:mama`，全量：`npm test`。本轮不调用付费模型、不修改赛事交付物、全局凭据或通道配置。Codex调用 `$my-mathorcup-bigdata`；羲和源码变更需下一次正常启动服务加载，技能文件可实时发现。
