# APMCM 赛事包与范文资料入口

在左侧选择项目，打开「🧩 模板库 / 方案」，从「模板库」选择「亚太杯 APMCM」，点击「载入模板草稿」再保存项目方案；随后新会话使用亚太杯主技能与论文骨架。也可在“新建会话”的赛事选择中直接选择 APMCM。已有通用、国赛、MCM/ICM 和 MathorCup 赛事包继续分别选择。仿真属于可叠加的方法模板，选择仿真方法时仍保留当前赛事规则。更换赛事会清理旧赛事的届次、规则与截止时间，重新核对登记；仅载入草稿不改已保存方案，已有会话保持快照。

本包提供英文赛项的阶段提示、主技能和 `contest_packages/apmcm/paper/main.tex` 论文骨架。`knowledge/apmcm/START.md`、`catalog.json` 和逐篇卡片是随包提供的历史论文蒸馏索引；原始 PDF 与逐页全文不随包分发。可在会话中用 `apmcm_reference` 选择年份、题号、方法或论文结构查看蒸馏卡。只提炼有证据的建模与写法，不把历史结果复制到新论文。原始压缩包不随包分发。

2026 年[官网参赛规则](https://apmcm.org/detail/2513?language=cn)附[扫描 PDF](https://files.apmcm.org/uploads/files/20261020/1792484391858628.pdf)。已核到的英文、摘要首页、页眉编号、匿名、程序附录与签字承诺书分开的条款及页码，见 [source-2026.md](../contest_packages/apmcm/source-2026.md)。包身份保持 `to-verify`，因为新项目的具体年份与赛项需确认；其他年份/中文赛项不能默认沿用。

论文格式的未知项保持未知：2026 此 PDF 未核到统一页数、文件大小、目录及 AI 声明位置，不能把国赛或美赛规则套入。算法库用于候选与代码范式；`academic_search` 仅在运行时可用且实际返回时用于方法文献与 DOI 核验，不能证明模型结果正确。结果必须来自本题可复现计算。
