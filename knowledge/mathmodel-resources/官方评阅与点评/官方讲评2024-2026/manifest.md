## 九、采集方法备注

- dxs 列表页文章由 JS 加载，经其 JSON API 枚举（列表 `/zx/json/<栏目路径>/`，文章元数据 `/zx/json/a/<catalog>/<yymmdd>/<id>.json`），正文从文章 HTML 的 detail-content 区块提取。
- 讲评幻灯片图片按 HTML img alt 中的原始文件名保存（如"数学建模评阅情况2025深圳_页面_01.jpg"），原始 CDN URL 记录于各目录 image_sources.json；已核对每篇 HTML 图片数与本地一致（slider 导航重复图已去重）。
- 全部下载用 curl（--ssl-no-revoke）；PDF 附件按原名保存；md 内相对链接已百分号编码并逐一校验（1301 个链接全部可解析）。
- 工作脚本与日志存于 `..\_work\`（targets.mjs 目标清单、fetch_reviews.mjs 主下载、fix_md.mjs 正文修复、scan_missing.mjs 补漏扫描、results.json 下载结果）。
