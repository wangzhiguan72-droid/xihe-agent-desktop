# APMCM 往届论文资料索引

本目录提供 2022–2025 年 APMCM 公开范文的元数据与蒸馏卡。`catalog.json` 记录年份、题号、可见页数与缺页状态；逐篇文字与原始 PDF 不随包分发。文件名含“优秀论文”不证明奖级，引用前以当届官方来源和可选的原 PDF 核对。

## 按题使用

1. 先读当届题面、附件与官方格式规则；本库不提供当前赛规或答案。
2. 按机制选择 1–3 张[蒸馏卡](cards.md)，记录相似点、差异和候选方法。
3. 抽取“目标—输入—约束—数学机制—求解—验证”的可迁移结构；不要复用历史数据、数值、结论、图像或未经许可的全文。
4. 方法出处与公式条件按当前题另查原始文献；可用学术检索工具搜索公开机制词，再按 DOI/出版者核验。题目专属数据和私有 PDF 不上传到检索服务。
5. 在项目的论文蒸馏记录里写明：相似点、差异、页码、候选方法、成立条件、当前数据的最小检验；缺页与不可靠数值另列。

## 从这批论文观察到的可复用结构

- 多数首张是 summary sheet 或摘要，按题问逐段报告模型、数值或图形证据与结论。实际写作时摘要中的每个数字要对应当前运行结果。
- 目录和正文常用逐问组织；基础假设、符号与数据处理先集中说明，逐问模型再交代输入输出。是否设置目录、摘要页等须依当届官方模板，不能从范文反推硬规则。
- 工程/物理题常以守恒方程、边界条件、数值仿真、参数优化和对照检验串联；预测题常以变量审计、可解释基线、时间切分、误差诊断和敏感性检验串联；优化题要同时报告目标值和约束可行性。
- 有些摘要声称“验证”但可见内容未足以独立复核；蒸馏卡只记录作者声称和可见结构，不认定结论可靠。

需要回读原页时，由用户自行提供合法获得的 PDF，并在本机只读使用；工具不会声称已读取未随包的全文。
