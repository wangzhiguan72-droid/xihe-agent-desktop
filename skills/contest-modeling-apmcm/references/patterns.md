# APMCM 历史论文蒸馏后的流程模板

来源：2022—2025 年 16 份公开范文的可见摘要、目录与模型章节；随包只附元数据与蒸馏卡，具体回查用 `apmcm_reference`。下列是归纳后的新模板，不是原论文结论、官方评分标准或固定算法要求。7 份原 PDF 疑似缺页，不能据此补写作者未展示的验证。

## 统一流程：沿用国赛证据链，独立配置亚太杯

题面契约与跨问接口 → 数据审计与规则来源 → 同机制案例选读 → 解释性基线 → 当前数据求解 → 针对缺口改进 → 同口径比较 → 独立核查与冻结 → 英文 Summary/正文/源码附录。可复用国赛“基线—迭代—冻结—交付”的组织方式；赛程比例、国赛质量偏好、页数和提交上限不随之迁移。

## 可直接用于起草的章节接口

每问正文按“本问目标及上游输入 → 假设与变量/单位 → 方程或目标/约束 → 求解设置 → 实际输出 → 核查/对照 → 回答与下游输出”组织。公式后解释符号及参数出处；模型名不能代替实际方程。图表优先安排机制示意、基线与改进的同口径结果、敏感性或约束检验；仅凭历史论文中的图片数量不设图量门槛。

英文摘要在结果冻结后完成：先一句交代本题目标；逐问写实际采用的方法、关键结果及其单位；最后交代验证结果与适用边界。保留自然段，避免把流程卡标题照搬为摘要。所有数字绑定当前正式运行及图表来源；没有得到可靠结果的部分明确说明，不填历史数字或演示指标。

## 算法库与 academic 的调用接口

方法卡与代码范式用于提出可检验候选；academic 用公开方法词补原始文献和 DOI。顺序为 apmcm_reference 筛案例 → skill_load 读对应方法/代码模板 → academic_search 按缺口核方法出处 → 本题数据正式运行 → 约束/预测/仿真验证。需要原文时只检索公开元数据，再回到实际可访问的论文核对公式。服务缺失不声称已检索；文献记录与数值运行证据分开。

本文件可随技能导出；原始 PDF 与逐页全文不随包分发。需要回读原页时，由用户自行提供合法获得的 PDF 并在本机只读核对；未回读时明确说明。
