# 本地模型字典（可选）

模型字典是外部检索索引，不随包分发。若用户提供自己的字典工作簿，可用随包脚本只读查询：

```bash
python scripts/model_lookup.py --file <字典.xlsx> --query "分段线性插值" --limit 3
```

脚本依赖 `openpyxl`，运行前确认当前解释器已安装该库。输出工作表、行号和字段定位，可回原工作簿核对；脚本只读，不判断模型正确。

候选卡需记录模型族、适用条件、数据要求、输入输出、假设、禁忌、缺陷及检验；近重复条目先按机制去重，不用条目数量冒充方案多样性。

字典是检索线索，不是理论证明。最低样本量、预处理、优劣结论须按题目及原始文献复核；例如“分段线性插值至少 3 点”不能视为数学必要条件，两点即可定义一区间线性插值。

没有字典文件时跳过本工具，按题目与可核实理论选路；在报告中说明“未查字典”，不虚构查询结果。
