# 技能组合与降级

`my-cumcm-fullflow`、`my-cumcm-zcode`、`my-cumcm-deepseek` 是同一流程的不同入口，一次任务只选当前宿主适用的**一个主控**。专长技能只接受范围、输入、产物和验收条件明确的子任务，返回证据与缺口；不再次启动 `math-modeling`、`cumcm-workflow` 等全流程总控。读到技能文本只是理解规则，显式调用要符合当前宿主的技能发现与调用方式；缺入口或宿主限制时由主控依照已读规则本地完成该环节，不能声称技能已执行。当前阶段的门禁和模式沿用 [工作模式与交付协议](工作模式与交付协议.md)。

**本轮范围优先**：按[逐问推进与阶段授权](逐问推进与阶段授权.md)先确定当前问/单元/停止条件；下表是按需路由，不是需要一次读取或立即运行的清单。先全局审题，再在当前问中做模型—计算验证—小节交接；仅授权进入下一问或全局整合时扩大执行范围。允许读取后问依赖与修订前问，但新主解按相应授权推进。

| 七阶段 | 输入与可选专长 | 必须回交的产物 / 失败回路 |
| --- | --- | --- |
| 1 读题与范围 | 题面、附件、当前项目状态；`bzd-problem-translator`、`problem-doc-model-selector` | 子问清单、字段/单位、初边值、约束、跨问接口和歧义；OCR/解析不清就回原页人工核对，暂不选模型。 |
| 2 候选与形式化 | 阶段1契约与 [算法库与 MCP 调用](算法库与MCP调用.md)；`bzd-modeling-ideas`、`bzd-model-dictionary`、`math-modeling-contest-route-selection` | 候选卡、符号、方程/目标/约束、失效条件与验证设计；M 门 `FAIL` 时返回题意、假设或公式，关键决策按已选模式处理。 |
| 3 数据与基线 | 原始数据只读、阶段2模型；数据审计或所选求解库 | 清洗规则与源哈希、最小可运行代码、输入输出结构、量级/边界结果；P 门 `FAIL` 时退回数据映射或最小例，不把主解图当基线。 |
| 4 主解与创新 | 已通过的基线、参数与版本；`math-modeling-solver` 中相关模板或实验专长 | 实际运行日志、原始结果、事件/报告双口径、图数据、对照或创新反证；执行失败保留负面日志，修复后重跑受影响链。 |
| 5 验证与复核 | 当前模型、代码、结果及适用反例；`bzd-model-solution-checker` 或独立审阅能力 | 解析/守恒/样本外/敏感性等题型适用证据、缺陷等级与 V 门状态；改变主要答案的反例回到阶段2或4，不仅写成局限。 |
| 6 写作与呈现 | 冻结或标明待核的数字、图数据和验证状态；方法/求解写作、`bzd-symbol-notation-checker` 等按章选择 | LaTeX 主稿、可追溯图表/引用、W 门状态；图文数值不合退回相应实验，版面问题回本阶段重渲。 |
| 7 终审与交付 | 当前源码、实编 PDF、日志、附件和 AI 使用记录；`bzd-paper-format-checker`、`bzd-reference-appendix-checker`、`bzd-ai-usage-disclosure`、`bzd-review-paper` | D 门、逐页检查、版本/文件清单、复现说明与未完成项；编译/引用失败回阶段6，模型/数值问题回更早阶段。 |

M/P/V/W/D 是附着在产物上的横向质量门，状态限 `PASS / FAIL / NOT_RUN / STALE / NOT_APPLICABLE`，不是额外阶段。修改模型、数据、参数、公式、图表或论文实质内容后，受影响的门与下游产物改为 `STALE` 并复核；独立审阅没发生就写“独立审阅未执行”。分章检查只取当前章节与依赖证据，避免全包重复加载。若任何专长缺失，主控保留上述最低交接字段，自行执行能验证的部分并标出 `NOT_RUN`，继续不依赖的工作。

## 图形分支与宿主限制

数据图先审数据、图型和结论，再用当前宿主确有入口的 `scipilot-figure-skill`、`nature-figure`、`mathodology-figure-presets` 之一；计算图必须绑定实际结果。工程/流程图默认 draw.io，保留 `.drawio` 源文件并导出 PDF/PNG。仅当用户明确选择 HTML/CSS 且 `html-paper-figure` 入口与本机渲染依赖确实可用时采用 HTML 路线；不自动下载 Electron，不借 MetaMath/“数学建模版”路径或配置。细节见 [图表规范与出图时机](图表规范与出图时机.md)。

绘图与呈现类技能只在当前宿主真实提供入口时使用。需要机制或概念图时，交锁定段落与用途；需要数据图时，交锁定的数据路径、分析目标、图型、尺寸与导出规格。不伪造调用协议、不绕过调用限制；可读取可访问的规则并按自身工具本地实现同等检查，实际调用状态如实记载。若宿主只准用户显式调用，遵守该限制。缺绘图工具时可交付图形方案与可编辑源草稿，标记未渲染、未目视检查，不把占位视为正式图。

## 实验与写作技能的部署检查

若安装了实验、方法论写作和求解写作技能，先确认当前宿主能解析各自入口，并核对同名依赖是否存在。主控交锁定题面/模型/最终代码/真实结果/验收字段，只运行当前阶段；生成代码后按当前授权真正执行，缺图不推断视觉结论，正式论文沿用 LaTeX/PDF 约定。按 [同类论文蒸馏与文献统计联动](同类论文蒸馏与文献统计联动.md) 把同类案例、DOI 和适配统计诊断接入上述证据链。未安装时由本技能完成最低流程，不阻断。
