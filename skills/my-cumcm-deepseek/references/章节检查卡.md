# 逐章写作和回检

从各板块详细说明提炼，按当前章节加载，不强制照搬章节数量和模板句式。

| 章节 | 检查核心 | 不应混入 |
|---|---|---|
| 摘要 | 标题准确；各问任务、方法、真实结果及验证；数字回指正文/台账；末尾只写已实现价值 | 教程、空泛背景、正文不存在的创新/数字 |
| 问题重述 | 保留任务条件、单位、目标，精炼转述；背景限必要内容 | 提前公布解法、照抄大段题面、强塞研究综述 |
| 问题分析 | 输入→数学对象→输出；数据支持、选型理由、约束、检验与实际跨问接口 | 算法名词列表、伪造串联、重复完整推导 |
| 假设 | 区分题面已给/情境推定/模型所需；依据、作用方程、影响与验证状态 | “模型准确”“数据无误”等自我证明 |
| 符号 | 全局核心符号统一、单位和范围清楚；局部变量就近定义 | 因查表机械改掉全文稳定符号、未使用符号 |
| 建立与求解 | 方程/约束/边界/算法与实际实现一致；参数及数据来源；明确回答每问 | 软件名替代算法、只有结果无解释、为了创新硬改适用模型 |
| 结果与检验 | 基线、改动、相同指标对照；范围与不确定性说明 | 调阈值迎合结果、把拟合当外部验证 |
| 总结评价 | 具体优势、已实现创新、真实不足、可行改进 | 把未来计划写成已完成；隐藏足以推翻结论的缺陷 |
| 引用与附录 | 正文主张→核实原始来源→首次引用；双向对应；代码/支撑清单可复现 | 为凑篇数列未引用文章、AI聊天代替学术原文、关键答案全藏附录 |

每个模型建立“依据卡”：任务、数学对象、数据条件、必要假设、输入输出、实际调整（可为无）、检验、跨问接口。
研究综述仅当有助于选型和论证时写，不固定500字；文献数量按实际引用需要，不以5/10篇为门槛。
引用格式统一、同源去重；联网查一般公开文献只核验原始来源，遵守当前比赛约束，不向搜索泄露私有题面。
每次审查返回“位置/事实证据/问题及影响/最小改法/依赖复验”，NOT_RUN与错误分开。同一根因合并，局部修复后重查关联部分。


## 结果能否被直接找到
每问结尾给出“最终答案→实际含义→关键检验证据与适用边界”，不让读者从多张图或原始输出中自行猜方案。按题目需要给数值/单位、区间、推荐方案、排序或决策表；题目问选择时明确推荐及成立条件。没有唯一解或证据不足时明确未决和原因，不为写结论而强选。
建立轻量的“题目要求→正文结论位置→表/图/验证位置”对应检查，可复用现有证据台账，不另造空文件。摘要与各问结尾对同一结果保持一致；支撑主要主张所必需的对照、误差和限定应在正文可见，附录保存细节，避免只靠附录支撑正文的强结论。

## 定向终审而非重复通读
最终版本按风险分别检查：摘要能否独立交代真实成果；各问结尾是否直接作答；假设是否实际使用且前后一致；公式/符号/单位/图表是否对应；验证是否针对主要误差来源；格式、引用、匿名、完整代码与AI披露是否符合适用规定。可合并为一次多维检查或按问题分工，不强制六遍全文、不增加固定计时阶段。局部修复只重查受影响链条；模型/结果改动则扩展复核。上述是质量检查，不是得奖公式。
