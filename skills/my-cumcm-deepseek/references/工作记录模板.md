# 工作记录最小模板

仅在跨阶段工作时建立，已有等价文件则复用。实际项目可以合并文件；不要为简单润色创建一套空台账。

context/workflow_memory.json 示例（值按实际填写）：
```json
{
  "schema_version": 2,
  "current_stage": "model_selection",
  "next_action": "compare_boundary_interpretations",
  "project_root": "<实际绝对路径>",
  "scope": "用户本轮范围",
  "preferences": {"language": "MATLAB", "interaction_mode": "semi_auto", "contest": "CUMCM"},
  "deadline": null,
  "authoritative_files": [],
  "decisions": [],
  "pending_questions": [],
  "critical_approximations": [],
  "claim_scope": [],
  "human_review": [],
  "runtime_profile": null,
  "evidence_status": [],
  "running_jobs": [],
  "checkpoint": null,
  "updated_at": "<含时区时间>"
}
```

决策记录 D-id：问题、可选路线、推荐依据、用户原意摘要、选择/授权范围、日期、可能失效条件。
关键近似：题目对象、实现表示、反例/对照证据、影响的问与结果、已接受/待讨论/失效状态。主张范围：仅可行/已搜索集合最佳/有界近优/有条件全局证明。运行档案：宿主、实际运行包版本、技能入口路径、输出目录、仍运行任务，不记录密钥或令牌。
来源 S-id：题面页码/附件字段或外部来源、支持哪一主张、已核验状态。付费资料只记本地位置和提炼，不复制整库。
结果 R-id：变量、原始精度值/单位、脚本、输入/参数哈希、日志、输出路径/工作表/单元格或键、运行时间及退出状态。
主张 C-id：论文位置、主张文本/限定、依赖的 R/S/D-id、验证状态。同一数值不同运行不能混同。
检查 G-id：判据、观察值、证据位置/哈希、PASS/FAIL/NOT_RUN/STALE/NOT_APPLICABLE、覆盖范围和未验证内容。
任务 J-id：命令、工作目录、开始时间、进程/会话身份、日志、退出状态、输出位置；恢复时核对旧进程，不盲目重跑。

恢复步骤：读取用户约定与状态→核对权威文件/哈希→识别过时证据与仍运行作业→说明已验证/待验证→继续唯一最有价值的下一步。

74小时正式比赛与创新轮次按需增加 contest_clock、baseline_status、assumption_register、active_iteration、validation_plan、freeze_status；字段意义和I-id模板见 [74小时基线与假设创新](74小时基线与假设创新.md)。沿用当前状态文件，不并列维护互相矛盾的state.json。

按需在现有状态添加 `capabilities`：入口真实路径/哈希、文件可读性、会话工具可见性、允许调用方式、探测时间和降级；阶段调用记录输入证据、所用技能/工具与版本、实际输出、运行状态与未验证项。MCP还记录服务器/工具/schema和作业标识，不记录凭据。结果R-id可增加报告值、换算/舍入规则和单位，与原始结果关联，见 [双口径抗幻觉](双口径抗幻觉.md)。

## 逐问审核的范围记录（可选，沿用现有状态）

按[逐问推进与阶段授权](逐问推进与阶段授权.md)记录execution_scope，不另建竞争的Task_State.json。字段是项目台账，不创造宿主弹窗/API或自动调度，也不把状态文本当外部授权凭据。用户实际请求/确认优先，恢复时核对输入版本与真实证据。

```json
{
  "execution_scope": {
    "progression": "question_checkpoints",
    "current_problem": "P1",
    "work_unit": "model_spec",
    "allowed_actions": ["formulate", "formula_check", "manual_small_example"],
    "input_versions": ["task_contract:v1", "route:P1-v1"],
    "authorization": {"user_message_summary": "选择方案2，先写问题一规格，不运行主解", "scope": "P1:model_spec"},
    "stop_condition": "deliver_model_spec_for_review",
    "waiting_for": "author_model_review",
    "human_review_status": "pending",
    "verified_artifacts": [],
    "handoff": {"formulas_units_assumptions": [], "results_uncertainty": [], "evidence_paths": [], "unresolved": [], "dependents": []}
  }
}
```

作者认可、执行授权与M/P/V/W/D技术状态分别保存。单一句“继续”能指向明确的唯一下一单元时按其有限范围记录；不能替用户选未决路线、换模式或无限跨问。上游修订将依赖结果/门禁/正文标STALE，详证留文件并可追溯。
