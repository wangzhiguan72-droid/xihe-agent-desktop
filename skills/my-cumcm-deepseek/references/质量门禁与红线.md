# 证据门禁与模型分类

所有门禁绑定当前输入、代码、参数、结果和文稿版本。状态用 PASS / FAIL / NOT_RUN / STALE / NOT_APPLICABLE；缺证据不等于已证明错误。每项保存检查对象、判据、观察值、证据位置、结论及范围。旧版通过仅对旧版有效。

**与主流程的关系**：七阶段是唯一主流程；M/P/V/W/D 是横向质量层，在对应产物形成后做后置检查，不新增第八阶段。模式为半自动时，关键 FAIL/重大取舍回到作者选择；模式为自动时，智能体可在授权范围内修复并记录决定。任何实质变更都会使受影响门禁变为 STALE 并要求重审。

| 门 | 最低检查 | 通过的含义 |
|---|---|---|
| M 建模 | 任务覆盖、假设来源与作用、量纲/分母定义、初边值、可识别性 | 方程与目标可解释且无已知核心矛盾 |
| P 最小运行 | 小例、边界/约束、输出结构和合理量级 | 值得扩大计算，不等于全量正确 |
| V 求解验证 | 按模型类型选择下表检验，结果与原始档案相连 | 在声明条件与容差下支持具体结论 |
| W 写作 | 逐问任务→方法→结果→检验闭环，图表和正文可追溯 | 论文忠实于当前证据 |
| D 交付 | 当届规范、实际渲染、当前版本一致性、复现说明 | 请求范围内交付检查完成 |

P0：导致目标不成立/结果不可用的核心问题；P1：实质影响主要结论或复现；P2：局部表达与呈现。优先处理具体根因，多个 checker 同一问题只保留一个修复任务。分数是辅助诊断，不作为真实官方评分。

评阅取舍补充：P0/P1按其对任务、主要结论和复现的实际影响处理；P2不机械升级为整篇否决。已有可信核心结果与突出贡献时，局部不足应披露并按剩余时间排序，不强制穷尽非关键改进。评阅参考不放宽真实性与核心正确性，具体题型见 [评阅要点与实质贡献](评阅要点与实质贡献.md)。

## 检验与模型匹配
- 机理/PDE/ODE：守恒、单位、边界和初态；解析或极限特例；网格/步长变化；独立离散方法。报告网格差的定义，不能冒充严格误差上界。
- 优化：原始约束残差、可行性、目标值重算、小规模穷举/精确解或上下界、多初值；启发式最好值不能宣称全局最优。
- 预测/统计：按时间/个体等正确划分训练验证，预处理仅拟合训练集；基线、外推边界、残差与不确定性；拟合优度不能替代样本外效果。
- 评价/排序：标准化方向、权重来源、排名稳定性、相关性和权重扰动；不以任意权重包装客观结论。
- 仿真/随机：随机种子、重复试验、Monte Carlo 误差与模型不确定性分开。
- 分段运动/覆盖：连接点位置、方向/速度及定义域一致；粗网格漏峰/漏接触；分区接缝漏测与重复覆盖。
- 情景联合生成：相关结构、比例联动与支持范围同时可实现，不能让多条两两关系相互矛盾；先固定策略，再在未用于选择的情景评价。
- 决策表回代：量纲一致，销量/需求/补货/库存不混用，成本/收入/利润不混用；每个最终方案重新计算原约束违背量。文字解释合理不能代替回代。
只运行适用检查，不让每题强制做 PDE 网格收敛，也不机械要求每问两种模型。
出现几何裁切、关键近似、概率认证或最优性声明时，补读 [关键近似与最优性](关键近似与最优性.md)。模型门检查表示是否忠实；验证门分别记录机制误差、数值误差与抽样误差；写作门核对全篇声明范围。

## 数值与导出
运行前定义判据。数值比较通常使用 abs(a-b) <= atol + rtol*abs(b)，记录参考侧、单位与阈值来源；文件副本才要求字节哈希相等。不要要求跨平台浮点结果逐字节一致。
工作簿核查表头、行列数量、模板映射、时间/空间坐标、缺失掩码、舍入精度和关键/全部数值，报告实际覆盖范围。公式单元格还要验证实际计算值，不能把空缓存当结果。
审计自己的日志可写；正式档案只读。隔离复跑必须检查绝对路径、缓存及外部依赖，防止意外覆盖。
正式提升前检查候选结果完整、日志成功、数值/结构通过；提升后核对文件哈希和对应文稿，旧产物保留为历史。

## 变更传播
题面勘误/原始数据→模型→代码→结果→图表→正文/摘要→最终渲染。
假设变更至少复核推导/实现/结果解释；实现改变重跑相关计算；仅列映射改变检查导出与值不变；局部措辞改变检查限定、符号、引用及版式。
若检查后文件改变，相应项 STALE，未受影响检查复用。保留失败实验与“本轮未验证”清单。

## 2026 A 题经验如何迁移
可迁移：经验公式解释域一致，干/湿基分母明确，跨问初态依据题面；共同变化不能单因素归因；负面对照要披露；旧图/旧说明要同步。
不可迁移：旧半径、时间、温度、四问数量、MATLAB 版本、网格和专门阈值。旧报告的 107 份副本、320 单元格等只说明当次覆盖，不是新项目门槛。
