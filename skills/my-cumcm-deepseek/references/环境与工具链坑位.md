# 能力检查与宿主兼容

## 按实际工具能力分级
| 能力 | 可完成 | 不可声称 |
|---|---|---|
| 仅聊天 | 题意讨论、公式、代码文本、执行说明 | 运行成功、读到未提供的本地文件、产出已编译 PDF |
| 文件读写 + Shell | 完整本地求解、日志、图表、可用渲染链 | 未提供的独立 agent / workflow / PTC 已执行 |
| 加上真实审阅 agent | 独立分工与复核 | persona 切换等于独立审阅 |
| 缺编译器/视觉工具 | 源稿、结构检查、待验说明 | 编译或逐页视觉检查通过 |

只探测本阶段必需项：所选解释器/求解器、实际依赖、可写输出目录，写作阶段才检查字体/渲染器。主求解默认MATLAB R2024b，指定Python则遵从；只检查所选工具，不要求两种语言同时存在。读 skill 文件不需要专用 Skill 工具；能读文件就可读取说明，但技能说明不能制造执行能力。

## 安装与运行分开
常见技能目录包括用户级与项目级的 `.agents/skills`、`.codex/skills`、`.zcode/skills` 等；每台机器以实际扫描配置为准。复制完整 skill 目录（含 references）后检查：
1. 文件存在及 frontmatter 合法；
2. 当前会话能发现或显式读入入口，能读取一个相对引用；
3. 在测试目录运行无私有数据的最小脚本、读回结果；
4. 若需要 persona，另做配置解析、挂载、切换、最小工具调用。
分别记录“文件安装/发现/挂载/执行”的状态。未运行的项写未验证，不能从某一层 PASS 推断全部可用。

无需 persona 即可读入本技能；不要求 Router、UltraMath、PTC 或特定服务包。纯聊天界面不会因复制目录获得本地工具。
若提供文件路径让宿主显式读取，需要它确有文件工具；没有时提供入口文本和所需参考片段，并诚实降级。

## 已发生的故障，不当作所有版本的事实
- 插件相对路径含 ?v=88：历史加载器把查询串当文件名，导致挂载健康检查失败。先看当前解析器对文件路径/URL的实际处理；不要全局删除所有 URL 查询参数。
- persona 的 text / prefix：历史升级出现 $.prefix missing required value。以当前安装包 schema 为依据，同时检查生成该配置的源模板，避免重启覆盖；不可盲目全局替换 text 字段。
- 切换后芯片回退/短暂 toast：菜单可见不等于挂载成功；记录实际报错，再看依赖、schema、插件路径。
- 400 被标成上下文超限：历史存在 OCR 模型被选为聊天默认模型的情况。检查真实响应、模型能力、provider 映射、上下文量，不能见 400 就清空对话。
- 3080 端口占用：可能是原服务仍正常工作；401 也可能仅是鉴权要求。先核对进程身份和服务状态，不杀掉正常会话。
- IME 字符乱跳：浏览器组合输入与编辑器节点变换/草稿回写是单独故障面，不能靠终端 UTF-8 或改 skill 修复；需要用户授权的 UI 最小复现，避免打断真实会话。
- 曾出现约 600 秒超时：先查当前限制，长任务分块/后台并保存日志、运行 ID、退出码。工具超时不代表子进程结束，重试前核对旧进程与产物，避免双跑。
- 安装停滞：核对版本、日志、文件和实际发现，不以目录非空宣布可用；重试有界，不无限重装。

修改 harness 配置属于另外的维护工作，先有故障证据、备份及明确范围；本 skill 默认不改全局模型、端口、凭据、preset 或 npm 缓存，不记录 token/key，也不擅自启动额外服务。

## Windows 与数值工具
- 含双空格的路径原样保留，使用 LiteralPath 和安全引用；不跨 Shell 拼接文件操作。
- Python 输出中文可使用 python -X utf8。PYTHONIOENCODING 只影响 Python 标准流，不能把已有 GBK 文件自动变成 UTF-8；读取日志先确认实际编码，再显式解码转换，保留原件。
- MATLAB Excel 混类型回读先统一数值/缺失值表示、核对域外掩码与表头，再用 isequaln 或明确容差；isequaln 本身不能修复 cell2mat 混类型报错。
- 无缓存隔离复跑前检查脚本是否会向绝对正式路径写入。只读审计可以写自己的报告，不能反向覆盖被审结果。
- 新源码与旧 summary、旧图、旧文档是常见误报源：以源码/输入/参数哈希绑定运行结果。


当前环境编译链与公式核验细节见 [赛场细节与低幻觉核验](赛场细节与低幻觉核验.md)。记录实际运行版本和失败状态，不能仅凭安装目录声称许可证可用。
