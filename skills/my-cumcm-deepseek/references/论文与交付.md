# 从证据到论文

## 写作路径
先确定权威代码、结果与图数据；给出证据大纲，每节列任务、主要主张和证据 ID。用户已有稿件则保留有效结构，只修当前范围。
逐問展开：现实任务与约束 → 为什么这个模型合适 → 必要假设与符号 → 方程及推导 → 可实现的求解设置 → 结果回答 → 检验和适用范围。
问题分析解释“为什么这样做”，不堆方法名称，也不提前复制求解结果。假设要说明为什么必要、作用于哪个式子、可能影响什么结果。不能为了短而删掉关键闭合。
摘要最后统一：各问任务、具体方法、经核验的关键结果与结论；没有数值就补实验或写诚实的定性结论，工作占位符不能进入声称完成的稿件。
同级标题语法一致、具体且准确，“改进/自适应/鲁棒”等称呼须有实现和证据。

## 润色
保留数值、因果方向、限定条件、变量和引用；去空话、重复和机器式套话，使解释适合本科生阅读。正文仍需足够推导，不能把节省 token 的极简输出模式用到论文。
可用 humanizer-zh 改善语言，不承诺 AIGC 检测分数，也不隐藏实际 AI 使用。
局部差分修改后查受影响的全文符号、编号、跨章叙述和摘要；不要求每次重新读无关资料。

## 图表与排版
图为明确问题服务，不定最低八图/九图指标。数据图由当前数值产物绘制并保留图数据；机制示意图标为示意，不画出不存在的计算结果。
统一绘图与排版规范见 [图表规范与出图时机](图表规范与出图时机.md)：含两类图路由（数据图→scipilot/nature-figure/预设模板，工程图→draw.io 工程图链，用户明确选择 HTML 且当前入口/渲染依赖可用时，才用 html-paper-figure）、出图时机表、图表契约五点、国赛版视觉基线（尺寸/字体/配色/导出）、多面板与四联闭合、自检闭环。正文图量按证据决定；全文写完且结果冻结后，再做候选图覆盖审计，不为凑数入文。绘制任何入文图前先按它确立契约。
用户偏好紧凑清楚：流程图上页大留白，先精简重复文字、合理调浮动与图尺寸；符号表溢出先改列宽/表述，避免只缩小字号或使用极端负间距。
正文格式、摘要字数/页数、匿名范围、附件和 AI 声明位置以当届规则为准；内部工作路径不用机械删除，正式提交包按规则检查身份信息。

## 格式与验证
LaTeX 是新稿和最终论文的权威源码；默认用当前环境实际可用的 TeX Live（优先 XeLaTeX/latexmk）编译，**最终提交件是实际编译并逐页核验通过的 PDF**。Word 可以同时生成，作为阅读/协作副本，不作为公式、数学符号、分页和最终版式的权威源；两种格式必须对账题目、摘要、公式、数字、图表、引用、章节结构和结论。没有实际编译、PDF 渲染和逐页检查时，只能交源码/阶段快照，不能称为提交版。
生成源码后实际编译/转换，检查错误、引用、字体、公式、表格、空白页、裁切与页码。缺渲染工具时如实说明。

## 截止与交付
记录用户时区和真实截止，按剩余时间预留复现、渲染、合规和上传余量。尽早走通基线导出，完整前称阶段快照。
临近截止比较创新收益/失败风险/耗时，建议冻结稳定版，但用户仍可选择探索分支；不让新实验破坏已有可用版。
最终文件以本次请求为准；仅在涉及计算或完整论文交付时，提供相应源码/支撑材料和运行说明。局部摘要修改不扩展成整套交付包；内部证据台账保留在项目，是否进入提交包依规则。
AI 记录从实际使用开始：日期、工具/模型（未知就未知）、用途、采用范围、人工核验；不重构伪造聊天记录。
检查当届规则时写来源路径或公开链接、适用届次、访问日期和未核验事项。本技能不提供已核验的当届法律/赛事结论。
最终审阅可以建议修改和给诊断分，但不预测保证奖项。制作交付文件不自动授权上传、提交或发送。

分页、符号表、Word副本和问题分析末尾可选引言按 [赛场细节与低幻觉核验](赛场细节与低幻觉核验.md) 处理，不改变既有首页及官方格式。
