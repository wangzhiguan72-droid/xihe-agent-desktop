# 同类论文蒸馏、文献与统计联动

这是按题执行的可选能力，不是预先保证收齐所有年份、题型或奖项的答案库。用户给出新题或继续已有项目后，先识别当前任务、比赛、年份和数学机制；沿用已选路线及已验证成果，只在相关阶段调用下面的能力。局部润色不重启检索或统计全流程。

## 1. 按当前题找近三届同类论文

优先读取当前可访问的同类论文索引技能，从其真实根目录按比赛、年份、题目和机制检索。新题默认考察此前三个已结束届次；以后按目标年份滚动。若用户指最近三个自然年或其他比赛，按其口径记录；正在举行或尚未公开的比赛不冒充已公布获奖论文。

先本地，再按缺口查官方公开优秀论文、评阅材料或其他有明确来源的全文。按“输入/约束/目标/机制”相似性匹配，不因同为A题或都用回归就认定同类；本科 CUMCM、研究生“华为杯”和 MCM/ICM 分别标识。论文是否获奖及奖项等级须有来源；只位于“优秀论文”文件夹时，记录为收录优秀论文、具体奖项待核，不靠目录名补造奖项。

随包不附私人论文合集；需要案例时只检索公开题名和机制词，不外发私人题目、附件或全文。缺年、缺全文或仅有摘要时如实记录，不声称全部获奖论文已齐。

选取确实相关且能阅读的少量论文逐篇蒸馏，保留可回查来源。输出或复用项目的“同类论文蒸馏”记录：

| 字段 | 必须说清 |
|---|---|
| 身份与来源 | 比赛/年/题号、论文题名、作者或队号（如来源公开）、获奖证据状态、本地路径或公开URL、所读页码 |
| 相似性 | 与当前题共有的机制、目标、约束；关键不同及不能迁移部分 |
| 建模链 | 题意抽象→假设→方程/目标约束→数据/参数→基线→算法→检验 |
| 可迁移精华 | 原理/结构如何帮助当前题、成立条件、准备做的最小验证 |
| 论文结构 | 摘要回答方式、逐问章节接口、图表证据组织、验证/局限如何收束 |
| 风险与出处 | 近似、泄漏、最优性与因果边界；每条归纳回指论文页码，不把历史数字、图表或结论作为当前结果 |

跨文总结共性和分歧，提出适配当前题的候选，不把多篇相似叙述当独立验证。只有摘要时可做摘要级筛选，不能声称完成全文精读或完整方法蒸馏。自动模式可按既有授权选路并记录；半自动模式按 [工作模式与交付协议](工作模式与交付协议.md) 交关键选择。

## 2. 用 academic-search 找方法原始出处与 DOI

先发现当前会话的学术检索工具；已存在的不重新配置。以当前工具面为准，不能因历史记录就声称未来会话已连通。它是学术检索工具，不是算法求解工具。

按需读取可访问的检索/引文核验说明。通过实际 `search_papers` 或当前同等工具用公开机制词/方法词检索，基础来源可用 CrossRef、PubMed、arXiv；付费数据库仅按真实权限和需要使用，不为证明工具可用而消耗配额。

先筛相关性，再用 `get_paper_by_id` 或原始出版商/注册机构核验DOI、题名、作者、年份和出版载体，保存支持的具体公式/主张与限制。查不到DOI就说明无DOI或未找到，可保留其他持久标识；不要求每篇竞赛论文都有DOI，也不编造。结果记入现有文献表/BibTeX，不能拿被引次数或检索排名替代方法适配性。跨源失败按实际错误换可用来源；细则见 [算法库与MCP调用](算法库与MCP调用.md)。

## 3. 合适的数据才调用 statsmodels

统计回归、参数推断和时间序列任务先确认当前可用的 Python 解释器及已安装的 `statsmodels`，使用前记录实际包版本。其他解释器不自动视为同环境。MATLAB 主求解约定不因 Python 统计辅助而改变。

明确观测单位、样本独立性、响应/解释变量、时间或群组结构、缺失处理和训练/验证边界。连续近似线性响应可从含截距OLS基线开始；二元/计数/重复观测或时间数据选择匹配模型，不把所有题都塞进线性回归。

回交系数/效应量、标准误、所用协方差估计、p值、置信水平及区间、样本数和模型设定；按数据与主张检查残差图或诊断、异方差、相关性、设计矩阵秩/条件数、影响点、收敛和样本外表现。常见可用接口：`OLS`、`GLM`、`conf_int`、`pvalues`、`het_breuschpagan`、`jarque_bera`、`durbin_watson`；按实际版本核验参数，不机械全套套用。DW本身是统计量，不能补造其p值；时序/组内相关需匹配推断设计，稳健标准误不能修复遗漏变量或因果识别。

用输入/代码/环境/参数及实际结果文件绑定证据；不显著、检验未拒绝或拟合优度高都不构成因果证明或假设成立证明。没有当前数据时仅准备代码/验证运行环境，合成数据演示必须明确标记，不能将其p值写进赛题论文。

## 4. 接到唯一主流程

上述三个分支回到同一证据链：同类论文提出可验证候选 → 原始文献支撑具体机制/公式 → 当前数据实际求解 → 诊断/对照与敏感性 → 当前论文。读取案例用于题意/候选阶段，文献贯穿选型与公式核验，统计在有适配数据的实验/验证阶段执行，最后按 [技能组合与降级](技能组合与降级.md) 交接写作与复核。不存在“读了获奖论文就保证正确”的捷径，也不需要每个局部请求重跑三个分支。
