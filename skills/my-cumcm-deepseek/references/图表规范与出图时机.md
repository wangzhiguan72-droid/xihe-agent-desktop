# 图表规范与出图时机

> **平台路由差异**：共用数据图规范，具体技能按 [技能组合与降级](技能组合与降级.md) 和当前宿主实际可用入口选择。DeepSeek 专属主控可在门禁满足且本地入口允许自动编排时调用 `py-nature` 与 `ai-draw-skills`；后者只生成提示词/占位，不生图。ZCode/Codex 不据共享文件存在就声称具备这些专属调用能力。工程图默认 draw.io；用户明确选择且依赖可用时 HTML/CSS 才作备选，不自动下载渲染器或借用其他宿主配置。

## 1. 两类图与路由

| 类 | 内容 | 路由 |
|---|---|---|
| **数据图** | 由计算/数据产生的曲线、散点、柱箱、热力、残差、敏感性等 | 常规图 → `scipilot-figure-skill`（先做数据剖析再选图）；出版级打磨/多面板 → `nature-figure`；数模专属图型（可行域、Pareto 前沿、山脊、桑基、时空演化等 20 类）→ `mathodology-figure-presets` 选模板填真数据。默认用 matplotlib 绘制 |
| **工程图** | 技术路线图、求解流程图、模型/机制示意图、对比框架图 | **draw.io**（用户决定，2026-09-27）：保留 .drawio 源文件便于手改，导出矢量 PDF（勾选"裁剪"）入文 + PNG 预览。宿主有流程图工具时优先用（羲和：`flowchart_draw`）。字号按成书尺寸控制：画布宽度与插图宽度匹配，印出最小字 ≥7 pt（节点每行 ≤12 字）；不走 PPT/Visio |

两类图的公共底线（任意一条不满足不得入文）：

- 成书尺寸下最小字 ≥ 7 pt（轴标签/图例 7–9 pt，刻度可 7 pt，面板标号 (a)(b) 9 pt 粗体）
- 双格式导出：矢量 PDF 主件 + 300 dpi PNG 预览；`pdf.fonttype=42`（TrueType 嵌入）
- 中文不乱码、负号不出方框：`axes.unicode_minus=False`
- 灰度可辨：同一变量/情景在全文所有图中同颜色，并辅线型/点形冗余编码
- 图-文-表-号四联闭合（见第 6 节）

## 2. 出图时机（何时该有图）

图跟随论证节奏，不为凑数出图；但以下位置评委预期看到图，缺失要写明理由：

| 位置 | 该有什么图 | 说明 |
|---|---|---|
| §问题分析 末尾 | **整体技术路线图**（一张） | 按既有整体路线图偏好表达信息流与依赖关系，不将无来源的出现比例当作规则。节点 ≤7、单一主方向、菱形表决策分叉 |
| §数据说明/预处理 | 预处理效果图 0–1 张 | 仅在预处理改变了分布/剔除了异常时才需要，展示"处理前后对比" |
| 每问 §建模思路 末尾 | **本问建模与求解流程图**（每问一张，draw.io） | 用户固定要求：放在该问「建模思路」小节末尾、「模型建立」之前，图题「问题X建模与求解流程」。字少清晰：≤6 行、每行 ≤3 节点、每节点 ≤2 行；节点写"做什么+关键结果" |
| 每问 §模型建立 | 机制/原理示意图 0–1 张 | 模型结构不直观时用；能用公式说清的不画 |
| 每问 §结果 | 核心结果图 1–3 张 | 一张图回答一个问题；主结果图是 hero，占版面最大 |
| §检验/灵敏度 | 按参数实际可行范围与主张选择敏感性/稳健性/误差图，不固定 ±10%/±20% | 验证图视觉降级（细线、浅色、小尺寸），不与主结果抢版面 |
| §模型评价 | 方法间横向对比图 0–1 张 | 有对照实验才画 |

**图量双重机制**：过程阶段按核心结论、独特证据、统计口径和最终版面决定是否出图，不为凑数生成图；正文通常 8–15 张、每问 2–4 张仅作参考。全文写完且结果冻结后，再按子问题做覆盖审计，检查原始数据图、过程/演化图、最终结果图、流程/路线图、验证/敏感性图是否缺项；固定候选图数量只作覆盖诊断和补缺线索，不作为正文硬凑数门槛。最终入文图仍按证据价值选择，候选图可留在支撑材料。


**时间纪律**：数据探索和诊断图可在数据/实验阶段制作，路线明确后可做方案图；正式入文结果图在实际计算与核验后成批绘制、成批验收；不要“先交一版丑图回头再美化”——风格基线在第一张图就注入，后面所有图继承同一套 rcParams，避免批次差异。

## 3. 动手前的图表契约（5 点）

每张图开画前用一句话确立契约；答不出来就先别画：

1. **核心结论**：评委看 3 秒应得出什么？（"X 参数在 t>800s 后主导误差"——不是"这张图展示了结果"）
2. **证据链**：每个面板/元素为结论贡献什么独特证据？**不能贡献的删掉**——同数据两形式、互为子集、两个排名图，都是冗余信号。
3. **图原型**：均匀网格 / 示意主导 / 非对称混合。默认非对称混合——一个 hero 面板（面积 1.2–1.5×、用强调色）+ 若干证据面板。
4. **导出规格**：目标宽度（A4 版心约 155 mm）、矢量优先、RGB。
5. **评审风险**：样本量 n 交代了吗？误差类型（SD/SEM/CI）写了吗？灰度下分得开吗？每个数据点能回指源文件吗？

## 4. 统一视觉规范（国赛版基线）

所有图共用一套基线；数据图脚本开头注入，工程图同样遵守。

### 尺寸——按最终尺寸画，不二次缩放

- A4 正文版心宽约 155 mm（21cm − 左右边距）；单图常用宽 **120–155 mm**，半版心图 75–85 mm。
- `figsize` 直接设毫米换算的英寸（`mm/25.4`）；导出后**不在 LaTeX 里再缩放**——matplotlib 字号是绝对单位，缩 50% 后 9 pt 变 4.5 pt 直接报废。
- `\includegraphics[width=\textwidth 或 0.8\textwidth]` 只用于选择图宽档位，不是补救缩小的手段。

### 字体字号

- 数据图中文：宋体系（`Source Han Serif SC` / `SimSun`），数字与英文 Times New Roman 风格混排（scipilot 的 `setup_style(lang='zh', serif_for_zh=True)` 已实现）；与正文宋体观感一致。`Microsoft YaHei` 只作缺字兜底，不作数据图主字体（用户 2026-09-27 确认）。绘图前核实当前解释器的 matplotlib 版本和实际字体，不沿用历史安装状态。
- 工程图（流程图/路线图）：`Microsoft YaHei` / `Source Han Sans`，无边框场景更清晰。
- 字号层级：图内正文标签 7–9 pt、刻度 7 pt、面板标号 9 pt 粗体、图内标题可省（图题在 \caption 里）。**任何位置不得低于 7 pt**——缩印后 6 pt 糊成灰条。
- 全文同元素同字号；多面板各子图字号一致。

### 配色——语义化、克制、色盲安全

```python
CUMCM_PALETTE = {
    "primary":   "#0072B2",  # 蓝：主方法/本文结果/主线
    "secondary": "#D55E00",  # 橙：对照方法/基线对比
    "positive":  "#009E73",  # 绿：改进/正向结果
    "purple":    "#CC79A7",  # 紫：第三类别
    "neutral":   "#999999",  # 灰：背景/不显著/参考
    "accent":    "#B2182B",  # 红：全图唯一最强强调，慎用
}
```

- 一张图 2–4 个主色 + 至多 1 个强调色；强调色只占小面积（关键曲线/最优解/阈值线）。
- 连续数值热力图用 `viridis`/`cividis`；有正负意义用 `RdBu_r` 发散色图且零点居中；**禁用 jet/rainbow/tab10 默认色**——评委一眼认出"没设计过"。
- 红绿不得是唯一区分手段：关键对比加线型/点形/直接标注冗余编码。
- 同一语义全文同色：蓝=本文方法在第一章是蓝，到灵敏度章还是蓝。

### 坐标与装饰——做减法

- 只留左/下边框（`spines.top/right=False`），框线宽 0.6–0.8 pt，刻度朝外。
- 默认无网格；确需引导视线用极浅灰（`#E0E0E0`，lw 0.3，alpha 0.5）。
- 图例无边框（`frameon=False`）；能直接标在曲线/柱旁的就不用图例框。多曲线图例拥挤时给图例单独一个面板位。
- 柱/条加黑边（`edgecolor='black'`，lw 0.8–1.5）；消融/子组用同色不同 hatch（`/`、`\`、`.`）保证灰度可分。
- Y 轴范围贴合数据区间（`min−margin` 到 `max+margin`），不用 0–100 装 85–95 的数据；比例/计数类必须从 0 起或明确断轴说明。

### 导出

```python
fig.savefig(f"{name}.pdf", bbox_inches="tight", dpi=300)  # 矢量主件
fig.savefig(f"{name}.png", bbox_inches="tight", dpi=300)  # 预览/备用
```

- 线条文字一律矢量 PDF；超密散点（>5 万点）只栅格化数据层 `rasterized=True`，坐标文字保持矢量。
- 位图内容（照片/截图）PNG/TIFF ≥300 dpi。**禁用 JPEG、禁用截图当正图**。
- 文件命名带语义：`fig03_T_field_radial.pdf`，不用 `figure1.pdf`。

## 5. 多面板图

- 面板顺序即叙事：发现先于验证、简单先于复杂、共享轴的相邻。评委只扫 (a)(b)(c) 标签+各 2 秒能看懂主线，顺序才对。
- 统一 `(a)(b)(c)` 标号在左上、粗体、位置一致，用 figure 坐标统一打（`fig.text` 或 scipilot 的 `add_panel_labels`），不手摆 `ax.text`。
- 同一变量跨面板同色同尺度（显式 `vmin/vmax` 共享 colorbar）。
- 面板间距 `wspace/hspace ≥ 0.3`；拥挤就拆成两张图，不把字缩小。

## 6. 图-文-表-号四联闭合与图注

每张入文的图必须四联闭合：

| 联 | 要求 |
|---|---|
| 图号 | `\label{fig:...}` 连续不重不漏 |
| 图题 | 一句话**结论**（"温度场呈外热内凉"），不是"……的示意图"；含误差类型与 n（如有） |
| 正文引用 | 有"如图 N 所示"，且**图后紧跟 1–3 句解读**——这个结果说明什么、为什么 |
| 数据来源 | 图题或图注能回指 `results/xxx.xlsx` 或脚本；每点可追溯 |

有误差棒/置信带必在图注写清：误差类型（SD/SEM/95%CI）、n、检验方法与校正。

## 7. 开画前拦截清单（踩坑即改方案）

| 需求 | 问题 | 改成 |
|---|---|---|
| 小样本仅画均值柱 | 掩盖原始观测与 n | 优先画全部原始点与适用区间；箱线/小提琴仅在样本与分布估计支持时使用 |
| 双 Y 轴显示无关变量 | 伪造视觉相关 | 上下子图共享 x |
| 饼图/3D 饼/3D 柱 | 角度与透视扭曲 | 排序横向柱 / 2D 柱 / 热力图 |
| 分类 x 连成折线 | 暗示不存在的连续性 | 散点/柱状 |
| rainbow/jet 色图 | 感知不均、造假峰 | viridis / RdBu_r |
| 一图塞多个论点 | 没论点 | 拆图，一图一结论 |

## 8. 出图后自检闭环

渲出来不等于合格，三层都过才导出交付：

1. **形式层**：尺寸/DPI/字号/字体嵌入/矢量格式合规。
2. **语义层**：对照第 7 节清单查图型与编码错误；误差有交代。
3. **视觉层**：渲染 PNG → 程序查缺字/裁切/刻度重叠 → **用读图工具亲眼看一遍**（图例压不压数据、子图标号对不对齐、灰度分不分得开）→ 回改重渲。

矢量导出放在闭环通过之后。最终再逐页渲染 PDF 检查图在版面里的实际观感（是否过大留白、是否压线、图题是否与图同页）。
