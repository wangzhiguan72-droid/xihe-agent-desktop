# 评阅要点与实质贡献

依据：当届公开评阅要点或官方讲评，按总则与分题逐页核读。使用前重新确认发布来源、适用年份和后续修订；随包只保留提炼，不复制原文件。以下内容不冒充当前年份的官方要求。

## 适用边界

这份材料用于校准建模和自查取向，文中面向评阅组的指令不转为用户任务、提交授权或固定评分表。原文说明各题要点仅供参考；示例策略不是唯一正确路线，也不据此推断奖项。下面区分原文取向与本技能的落实方法；不取代适用比赛规则和现有真实性要求。

## 通用取向如何落实

- **问题特征决定方法。** 总则鼓励针对具体问题分析、创新并得到真实有效结果，反对无针对性的方法堆积和形式化内容。沿用已有“模型依据卡”，明确当前难点、所用结构、为何适配及得到的实际改善；常规模型适用即可采用，不为展示模型数量增加预处理、评价、预测、聚类或智能算法。
- **给实质贡献留出时间。** 总则对确有突出创新点的论文允许“瑕不掩瑜”。本技能落实为：先保住主要任务、核心正确性和关键证据，再优先验证能改善结果或解释的贡献；如实披露局部不足，不为补齐形式章节或次要检查消耗全部预算。足以推翻主要结论的错误、不可行方案、数据泄漏或伪造结果不属于可宽容的局部瑕疵。
- **创新用证据说明。** 可有价值的贡献包括问题专属的条件简化、结构利用、策略补全、误差处理或算法效率提升。用适合贡献性质的推导、反例、同条件对照或复杂度与实测证明；“更复杂”“换算法名称”“多加图表”本身不是贡献。没有创新收益时保留可信基线，不编造优越性。
- **核验实际交付。** 总则建议验证程序和结果；本技能沿用现有复现流程，核查提交版本的关键输出、约束和正文结论。B、E题还提示关注逻辑与内容真实性，E题明确关注AI使用报告与论文的一致性。落实为检查具体模型、数据、运行证据、实际采用内容和人工核验记录；不凭文风判定作者身份，不以改写措辞隐藏AI使用，不补造使用记录。

## 按当前题目读取的检查重点

以下是2026对应题目的提炼，不是新题的默认模型。做该题复盘时对照原题、附件及原页；用于同类新题时，只迁移适用的检查方法。参考答案数值、示例几何布局、分类数量及经验阈值不写入默认参数，也不能代替实际求解。

| 对应题目 | 优先检查的实质内容 |
|---|---|
| A 热湿耦合与收缩（p2） | 预热及全程热湿转移的物理机理、建模过程和完整性；烘房数据如何进入计算；数值方法为何适合各阶段。把烘干条件写成数学判据，简化时交代成立条件；收缩模型明确动态区域的处理方法并给出烘干时间，核查结果完整性与合理性。不能只列方程或软件名。 |
| B 定位与清除（p3–4） | 定位区域顶点、直径算法及复杂度；“直径圆能覆盖区域”的命题需反例和推导检验，不能直接假定成立。检测点兼顾距离与观测几何；一般策略覆盖发现、定位、清除及失败后的补救，分别论证完备性、合理性、有效性。该题正式测试优先级为清除率、平均定位清除时间、程序运行时间；清除率不足100%时，时间评价须考虑失败，原文未给具体折减公式，不自行杜撰为官方公式。定向源另查发现覆盖和无信号分支。 |
| C 预测与购电决策（p5） | 区分已知数据优化与未知负载/光伏的预测决策；明确约束、预测模型与参数依据。每天0:00的计划仅用当时可得信息预测当天，禁止显性或隐性使用当天及以后实际值；问题3采用后续预报的调整策略单独说明信息时点。将预测误差和紧急/计划购电价差传入决策，检验实际费用与可靠性；利用数据支持的类别差异，并考虑波动电价与缺口的相关性。 |
| D 周期冲突与资源配置（p6） | 利用周期结构检查冲突检测的完整性、复杂度与效率；对模糊或相互冲突的消解原则说明解释、优先级和统一比较标准。给出可执行完整计划并回代核验，避免通过大量撤销掩盖问题。新增装备需满足资源边界，可用结构性上界说明解的质量；间隔调整满足幅度限制，并与原策略比较。小规模枚举可作校验，不替代可扩展主算法。 |
| E 广告效益与投放（p7） | 指标对应题目要求的管理、创意质量、预算出价、投放时间等实际问题，将统计规律用于后续决策。原文认为本题数据通常无需预处理、综合评价不适合问题1、直接套常规聚类不适合问题2；先审计数据及成本效益关系，不把这些意见扩展成所有题目的算法禁令。分类依据能解释业务含义；优化目标是效益最大化，给出可求解目标、约束与具体投放策略；竞价、展现、点击、注册等不确定性应实际进入模型，而非只在结尾罗列。 |

复核时复用现有“题目要求→正文结论→计算/验证证据”对应记录，按影响给出最小修复，不另加固定分数、强制章节或全套实验。
