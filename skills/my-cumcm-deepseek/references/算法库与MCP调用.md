# 算法库与 MCP 调用

本参考服务于七阶段主流程中的候选、基线、主解和验证，不能把索引、模板或远程返回值直接当成题目事实与求解证据。先读题面和原始附件，明确目标、变量、约束、单位、评价口径，再按以下顺序找方法；模型与门禁仍由 [工作模式与交付协议](工作模式与交付协议.md) 统管。

## 本地发现顺序

1. 若当前环境提供全局知识库入口，按题型只展开相关方法卡及来源表；路径不存在时记录缺失，按题目与可核实理论选路。历史 PDF 或笔记只作方法线索。
2. 需查模型字典时按 [模型字典检索](模型字典检索.md) 使用随包 `scripts/model_lookup.py --file <实际字典.xlsx> --query <关键词> --limit <数量>`；先确认文件、解释器和 `openpyxl`。字典不随包附带；缺失时标明未查字典，继续查方法原理和文献。字典条目需去同机制近重复，适用条件与样本量要复核。
3. 需代码范式时先解析当前可访问的真实入口。读取与题型对应的 cookbook、playbook 或模板，运行前核实公式、依赖、数据结构和许可证；目录或模板存在不表示代码已运行。只提取当前问题所需方法，不启动另一套全流程或继承机械暂停、固定模型数、图量和交付默认。
4. 回归、统计推断或时间序列任务可检查当前 Python 解释器中的 `statsmodels`。记录实际解释器与包版本；新项目主求解默认 MATLAB R2024b，用户指定或项目约定优先。用 Python 做统计辅助、数据处理、绘图或文档转换，不自动迁移已验证的 MATLAB 主解。

候选卡至少写明机制、公式与原始出处、输入输出及单位、前提与失效边界、数据要求、求解器/参数、基线和验证方法。关键公式先做量纲、定义域、边界或最小反例检查，再编码；软件退出码、模板输出或另一模型复述不能证明数学正确。计算结果必须有实际运行的输入、代码/环境版本、参数、原始精度结果与日志；报告舍入另留口径，见 [双口径抗幻觉](双口径抗幻觉.md)。

## MCP 与远程工具边界

- 先列当前会话实际可用的服务器和工具，再读 schema 与副作用；记录输入输出和运行证据。历史可用性不代表当前可用。
- 只读检索优先；写入、删除、外发或调用付费额度需要用户明确授权。
- 工具缺失、超时或协议错误时走本地回退：读文件、用本地求解器或公开元数据检索；先核对旧任务，再决定是否重试。
- MCP 返回的方法、文献或数值必须回到原始来源或当前运行核对；不得把工具调用成功写成模型正确或论文通过。
