# 宿主路由与断点恢复

本技能是唯一主控；专项文献、编程、图形和排版技能按需要做边界明确的子任务，不同时启动国赛或其他全流程主控。技能加载成功只说明正文可读，不说明任何专用工具可执行。Codex、羲和、DeepSeek、ZCode 的能力与权限以当前会话实际工具面和测试调用为准；缺工具时用现有本地能力完成相同可验证工作，或明确未执行。`my-cumcm` 仅供设计来源和可复用方法参考，不作为运行依赖。

路由按**当前项目显式配置**而非“某模型一律某通道”：检查角色模型、实际 provider、认证有效性与所需格式接口；记录请求、真实返回和回退原因。用户曾选过的 GPT-6-Astra/DeepSeek 通道配置仅适用于该项目当时环境，不能把代理地址、登录状态或测试通过结论写为新会话保证。用其他通道的审核须遵守私有题面和附件的传输授权与当届规定。

恢复清单：当前需求范围与授权、权威入口、题面/官方规则版本、代码/输入/结果/PDF/包哈希、各问状态、待完成作业及进程身份、最后成功运行和首个错误、旧结论失效范围。先判结果是否已经完成并留下证据，再决定续跑、局部重跑或人工核查；远端状态不明不得自动重复产生副作用。恢复后只报告已核、待核、下一动作，避免把旧记忆和新文件名拼成一个虚假的完成态。
