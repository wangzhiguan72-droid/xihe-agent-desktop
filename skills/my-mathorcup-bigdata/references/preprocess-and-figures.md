# 数据预处理与图形：按目标选择，保留验证

来源：用户2026-11-03提供的七张博主截图和文字，仅作方法线索。参考 [scikit-learn缺失处理](https://scikit-learn.org/stable/modules/impute.html)、[预处理与泄漏](https://scikit-learn.org/stable/common_pitfalls.html)；具体API以实际安装版本核对。先判断题目目标和观测语义，再选方法，不执行“所有数据必走五步”的固定流水线。

## 数据证据链

原始输入只读，清洗输出另存。按变量保留原值、QC/缺失掩码、异常原因、插补标志、方法和参数；汇总逐年/季节/时段/站点的有效率、最长连续缺测及关键事件窗口覆盖。对9999.9、QC=8等线索先查数据字典，确认缺测码/标志含义，不能对任意文件统一替换同一数值。全年时间戳不等于全年有效观测，时间边界依据实际有效值；跨年比较统一有效窗口、闰年和时区。

| 决策 | 准入与反例 |
|---|---|
| 重复与类型 | 按站点/传感器/变量/时间/产品版本等联合键识别重复；最新文件可能是修订或事后产品，保留血缘后选择。文本日期、时区、单位及分类语义明确后再转换，编号不是连续量。 |
| 异常值 | 先查物理边界、仪器状态、QC、跨变量和邻时一致性。极端事件可能正是研究对象，不能仅按3σ或箱线图删掉。对标记、剔除、稳健估计做目标相称的对照，留原值。 |
| 缺失与插补 | 缺失比例低于5%不是删除许可；缺测集中在灾前窗口时风险尤其大。区分缺测机制、连续缺口、时变过程和观测域，给插补前后敏感性。未观测区域/全nodata不能靠插补伪装成实测覆盖。 |
| 时序插补 | 短缺口且过程足够平滑时才考虑线性等方法，突变/极端窗口及长缺口需单独检查。预警评估只能用当时可得信息；双侧插值、平滑和全样本趋势会泄漏未来，事后重建须单列。 |
| 均值/中位数/KNN/MICE | 均值会压低方差，随机填数不自动保留联合分布；KNN需考虑尺度和邻域。MICE并不自动解决MNAR（非随机缺失），须说明识别假设与敏感性；填补、调参和标准化均只在训练折拟合。模型原生支持缺失也须验缺失是否承载标签/时间信息。 |
| 量纲与变换 | 标准化、Min-Max、对数等按算法需要选择，保留逆变换与原物理单位。Min-Max对极值敏感，对数需处理定义域；中心化不等于差分，分箱会丢信息。评价指标的正向/适度化要有目标和物理依据，不能机械改变所有变量的极性。 |
| 编码/特征/降维 | 名义类用合适编码，不用整数大小制造顺序；目标编码在训练折内交叉拟合。窗口特征按实际信息截止生成；85个特征或多算法融合不是默认优点。PCA/LDA、特征筛选、权重估计均防泄漏，并用样本外检验说明是否值得增加复杂度。 |

数据切分先于拟合处理参数。有效独立样本量按事件/站点/空间块判断，不把密集时次、同源产品或滚动起报当独立灾害。站点—口岸、站点—源区分别核坐标和支持域；一个距离或站点背景不能证明源区局地触发机制。

## 图形从要证明的关系出发

先列“问题→结论→证据→最清楚的图或表”。有信息增益才画；解析结果、表格或朴素曲线足够时不换复杂图。不强制每问固定数量、不以3D/弦图/雷达图代替检验。

- 相关矩阵可用热图，注明样本、窗口与缺失处理；相关不等于因果。灵敏度曲面仅在二维参数网格有实算支持时使用，必要时等高线比3D更易比较。
- 桑基图用于可核对守恒/收支的流量；弦图用于确有方向/权重的关系；雷达图需可比尺度、指标方向和轴序敏感性，不用多边形面积包装排名。地图注明CRS、比例和来源，不能把插值精度当原生分辨率。
- 低饱和、高区分度，保留必要强调色，兼顾色觉与灰度；同语义在全篇同色。通常少量字号层级即可，最终版面尺寸下检查字、单位、图例、负号和中文；“无缺字警告”不等于字形正确。
- 定量图由冻结数据和真实程序生成，保留数据键、代码、参数、矢量PDF/SVG及所需PNG预览。draw.io/PPT/Visio可用于可编辑机制图；流程图表达已锁定的方法，不从素材反推方法。AI图可作布局草稿，正式示意图需逐项核验/重绘；AI生成的曲线、地图或数字不是定量证据。
- 在最终PDF查看裁切、缩放、遮挡、字体、负号、图注与正文一致性；矢量或300dpi只是技术属性，不证明结果正确。修图影响数值时回到计算链，纯版式修复只验导出层。
