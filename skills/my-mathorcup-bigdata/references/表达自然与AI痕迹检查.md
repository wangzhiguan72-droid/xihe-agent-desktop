# 表达自然与 AI 痕迹检查（诊断清单，不打分）

用途：写作与终审时逐段诊断"模板腔/AI 腔"并改写。不是检测分数预测器，也不是藏匿 AI 使用的工具；AI 参与仍按当届规则如实披露。与双口径、七条补强硬检查分工：本文件只管表达层，数值同源、文献真实性、文码一致性由相应检查负责。

## 一、总判据：先证据，再修辞

每句先问：有没有具体对象、数值、口径、条件、章节或结果文件指针？

- 有 → 低风险，保留。
- 只剩抽象修饰、总结、铺垫、过渡 → 高风险，删掉或换成具体陈述。

示例：

- ✗ "该方法显著提高了精度。" → ✓ "相对线性搜索，迭代次数由 50 降到 4，两次搜索结果同为 1e-6。"
- ✗ "模型具有较强的鲁棒性。" → ✓ "参数 ±10% 扰动时，目标值偏差 < 0.1%。"

## 二、语言层高频特征

1. **连接词套话**：综上所述 / 进一步 / 此外 / 与此同时 / 值得注意的是 / 由此可见 / 一般来说 / 不仅…而且 / 当然。判据不是绝对次数，而是"是否带信息"：同段连用、每节开头同款、只做过渡 → 删。BZD 框架给出的参考密度：高频连接词占全文句数 >25% 为高风险；同一套话两次出现间隔 <5 页视为机械重复。
2. **三项排比**：形容词排比（准确、鲁棒、高效）和"应用于交通、医疗、金融"式空列举 → 改成带数值或对象的分条。
3. **同构句式**：连续"采用 A 进行…，采用 B 进行…" → 需要保留结构时，每句补对象与选择理由。
4. **被动与空主语**：被动句成片（>30%）→ 改"选择 X，因为…"；"可以认为 / 不难发现 / 众所周知" → 直接给依据。
5. **拔高词**：具有重要意义 / 显著提升 / 奠定坚实基础 / 彰显价值 / 有效解决 / 完美实现。后面必须有量化证据，否则降级或删除。
6. **句长与段落规律**：AI 文本句长集中（约 15–25 字、方差小），段落多为"主题句+解释+例证+总结"且段长相近。数模正文允许 5–10 字的短判断句与长推导句交替；删段末复述句。
7. **元话语**：每节"下面将 / 接下来我们"、每图"从图中可以看出"、通篇编号清单化 → 只留必要处。

## 三、GPT 写作专项（防御性、罗嗦、过度谨慎）

- **防御性铺垫**：需要指出的是 / 值得一提的是 / 不可否认 / 在某种程度上 / 一般而言 / 可能存在。一条判断配一条依据；不确定就写区间或条件，不用"可能"含糊带过。
- **过度谨慎**：反复声明局限却不说"在哪里、多大、怎么缓解" → 局限写成范围 + 影响量级 + 处理办法。
- **罗嗦**：同义重复、一句话拆三段、先总结再复述、段末再总结 → 压成"结论—证据—条件"。
- **空转过渡**：只起连接作用的句子 → 直接进入下一判断。
- **过度对称**：三项列表、一方面/另一方面、每段收尾金句 → 按信息量分条，不追求形式对称。
- **大词与生僻词**：能用常用词就用常用词；术语限于学科必要（LightGBM、CVaR、SOC 等），非术语不堆"范式 / 赋能 / 耦合 / 张力 / 抓手 / 底层逻辑"。
- **语体底线**：保持正式书面学术语体，不口语、不网络化、不粗俗；简短不等于随意。

## 四、改写流程

1. 标出可疑句：套话、拔高、防御、重复、超长同构。
2. 逐条处理：删除，或换成"对象 + 数值 + 口径 + 条件"。
3. 保护项：数值、口径、术语、引用、公式、LaTeX 结构一律不动；只改表达，不改主张。
4. 重点抽查：摘要、各问结论段、图前后两段。

## 五、边界

- 不预测检测概率、不以"骗过检测器"为目标；风格自然与如实披露并行。
- 事实层缺陷（文献虚构、数值跨处不一致、代码与正文不符）不能靠改措辞掩盖，交对应硬检查处理。
- 参考资料：BZD《数模论文 AI 痕迹审计》v2.2 语言层（仅作诊断框架，分数与权重不作依据）；humanizer-zh；用户材料《AI率检测参考》（高频词、句长与段落分布）。
