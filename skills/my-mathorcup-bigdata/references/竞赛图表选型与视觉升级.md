# 竞赛图表选型与视觉升级

用于正式定量图、论文组图和已有图的改版。先写清读者需要从图中判断什么，核对数据结构、单位、样本量和比较口径，再从下表选一种主图。已有图足以支撑正文时，只统一样式。改版涉及筛选、汇总、归一化或尺度变化时，回查冻结结果并同步图注及受影响的正文。

## 按读图任务选型

| 要读出的信息 | 可选升级 | 使用条件 |
|---|---|---|
| 趋势与不确定性 | 细实线叠浅色置信带、预测带或情景带 | 逐点使用实际计算的上下界。图注注明区间含义、水平、方法及适用的样本量或独立单位。环境极差和情景包络按实命名。只有单条估计时，可给主线加固定笔宽的浅色衬线，图例仍只表示该曲线，避免画成上下界。 |
| 多组曲线的趋势或传播 | 共享尺度小多图、按组热图，或三维墙图／瀑布图 | 需要逐点比较时优先小多图。三维视图适合有自然顺序的时间、位置、情景和剖面序列，须标明确切轴值、检查遮挡，必要时配关键二维剖面。无序组用同尺度分面。 |
| 整体构成 | 环形图、堆叠条或排序横向条形图 | 环形图适合少数非负、互斥且覆盖整体的类别，直接标百分比，中心可放总量。需要比较近似占比时用排序条；需要比较分组总量及构成时用堆叠条；只比较构成时明确采用 100% 堆叠与各组分母。 |
| 排序、成对差异或多组数值 | 右伸横向条、双向横条、分组横条 | 长标签或排序用横条。双向横条用于两侧有清楚语义且可用同一尺度比较的两组，标清两侧名称、零线和原始数值符号，镜像展示的正值在两侧都标正值。多组逐类对比用分组条或分面。条长表示量值时保留真实基线。 |
| 多维方案画像、长周期重复 | 雷达图、圆形／螺旋条形图 | 雷达图限少量方案及可比、同方向且已说明归一化的指标，避免用面积判优。圆形或螺旋布局仅在月份、相位等周期顺序有意义，且能清楚解释零点、圈与数值刻度时考虑，精确对比优先二维图。 |
| 相关、矩阵结构或二维场 | 热图、热图加边缘条形图、等高线 | 非负规模用顺序色标，有符号且有自然中点用发散色标。相关矩阵注明算法、样本口径并以零为中心，不用类别矩阵插补等高线。只有两个连续坐标上的实算网格或经验证的插值场才画等高线，遮蔽无支持区并注明插值及分辨率。边缘条形图应提供独立信息，如组样本量。 |
| 分布与异常 | 小提琴叠箱线、小样本原始点、ECDF | 组内样本及连续分布支持密度估计时叠加小提琴和窄箱线，图注交代 n 和箱线含义。小样本、离散值或大量同值优先点图或 ECDF。异常点按原口径保留或明确标注过滤规则。 |
| 两变量关系与第三个量 | 气泡图、带边缘分布的散点图 | 气泡面积对应可解释的第三个非负量，保留尺寸图例和必要的叠点处理。只有两个变量时用等大小散点。拟合线与区间各自说明统计含义。 |
| 流量、空间与机制 | 桑基图、弦图、地图、可编辑示意图 | 流量图核对收支、方向、单位和权重，地图检查坐标系、来源、比例和观测覆盖。机制图依据已定的模型重绘，草稿中的模块、方向和标注逐项对照正文。 |

## 一篇论文共用一套视觉规则

- 在第一张正式图前确定系列顺序、颜色、线型、符号和最终尺寸。同一方法、情景或量在全文用相同编码。常用一组低饱和主色和灰色基线，强调色用于需要读者注意的阈值或结果。可从 ColorBrewer 的分类、顺序、发散色板出发，实际检查灰度分辨与正文尺寸下的对比度。
- 中文数据图优先宋体系（宋体或思源宋体），英文和数字优先 Times New Roman。完整英文稿采用其模板指定字体。字体可替换时检查实际可用字形和回退，按插入论文后的尺寸设轴名、刻度、图例和面板标号的字号，一般保留两到三档。模板另有要求时使用当届规范。
- 主次靠留白、线宽、标注和版面分配。使用浅背景、细轴线与必要的参考线，省去无信息的阴影、发光和立体装饰。组图可组合趋势与残差、热图与样本量、分布与达标率。每个面板应回答相关但不同的读图任务。需横向比较的面板共享尺度和色标；其他面板标清单位与范围。
- 正文图号和图题依当届模板，通常图号与简洁图题随图下方的图注，图内保留必要的轴名、单位、图例、面板和阈值标注。正文解释图支撑什么判断。真实数据及脚本生成定量图，保留矢量 PDF/SVG 或规定的主件和所需位图。把图放回最终版面，逐项检查缩印后的字形、线型、灰度、重叠裁切，以及图中数值、图注、正文与结果文件的一致性。
