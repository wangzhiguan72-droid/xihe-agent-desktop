# 妈妈杯大数据竞赛赛程与逐问流程

此流程与国赛模板分开维护。赛程从当届官方截止时间和已用时间倒排，不套固定 74 小时、固定冻结时刻或固定题数；已完成项目只做本轮所需阶段。半自动/自动遵循用户已有授权；重要建模路线、实质假设、创新采纳在协同模式下交作者选择，普通本地修复连续完成。用户明确要求自主完成时不因旧模板的“首次只审题”停工。

| 节点 | 交付与准入 | 必须分开的状态 |
| --- | --- | --- |
| 赛事档 | 赛项、赛道、年份、题号、规则来源、真实截止与提交渠道 | 历史规则/本届规则；项目计划/官方时限 |
| 读题与数据可解性 | 逐问题目契约；附件清单；字段、单位、时区、空间支持、掩膜、来源血缘、事前可得性 | 下载/能打开/目标有效/科学可用；文件数/独立样本数 |
| 各问基线 | 规格、最小可运行求解、输出键、量纲与边界反例 | 条件计算/目标实证；内部预测/真实业务预警 |
| 跨问交接 | 前问结果实际被后问读取，接口、原精度、时间支持与有效域可追溯 | 上游科学结论/下游工程输入；旧分支/当前分支 |
| 方案改进 | 预登记要改善的缺口、同口径对照和停止条件；负面结果保留 | 结构变化/数值调参；同内核复跑/独立验证 |
| 复算与论文 | 关键数值独立复算、分歧处置；摘要、正文、附录与 AI 记录同版 | 编译成功/内容正确；复算一致/机制正确 |
| 提交准备 | PDF 逐页、目录页码、源码附录、匿名与 ZIP 条目、签署件待人确认 | 生成提交包/在线提交回执 |

采用数据证据矩阵：每个输入写原生文件及版本、采集/发布/有效时刻和时区、空间覆盖与目标有效像元、变量单位/时间累积语义、是否观测/重建/同化/预报/设计情景、与其他产品的共用依赖、所支持的问题与不能支持的结论。`.part` 等未完成文件不得进冻结清单。文件夹中的 `pre/post`、`independent`、`30m` 只是线索，不证明时间、独立性或有效分辨率。对 ZIP 先查结构、字段和缺口；bbox 相交后继续查 CRS、掩膜与目标有效值。空间覆盖数、正厚像元数、实际参与计算数分别留分母。跨量纲变量不混作同列统计。

时间线至少区分题设时刻、观测时刻、模型有效时刻、产品发布时刻与预警发送时刻。预测样本只能使用起报前可得资料；不能先按真实结局裁掉“不相容”样本后再宣称覆盖。对于概率/区间报告，写目标、样本单位、条件与无条件质量、分母、独立性和区间性质；未达/右删失不偷偷删除。

冻结是针对权威输入/代码/结果的版本约束，不是禁止修真错误。编译或图形错误可只修导出层并核数值未变；科学输入/公式变化则重跑受影响计算和下游文字。阶段完成只对声明范围有效，不能把“单问条件模型完成”写成“全题实证完成”。
