# 妈妈杯大数据竞赛工作流

本技能是 `my-cumcm` 的独立赛事变体，一次任务只选一个全流程主控。适用于 MathorCup 数学应用挑战赛**大数据竞赛**；其他 MathorCup 赛项与年份先查自己的官方题面、格式、AI 规定和提交入口，不自动沿用本届条款。用户只要求单问、修复、复算或终审时，只推进该范围，沿用已有授权和当前项目语言，不重启整题。已授权的本地可逆修复与验证继续做；公开发布、外发、提交、删除原始资料和代替队员作人工确认需另有权限。

## 起手定位

读取本届题面、附件及勘误，记录赛项/赛道/年份、选题、官方规则来源与访问或取得日期、实际截止时间和时区。确认项目权威代码、结果、论文、附件包及最新状态，检查报告对象哈希；发现旧路径或旧统计，不以“最终”文件名、旧对比结论或修改时间替代当前版本。读取 [赛程与逐问流程](references/workflow.md)。赛事规范和 AI 披露涉及本届交付时读 [2026 规则档](references/rules-2026.md) 并重新核当届来源。

羲和宿主先读 [羲和模式运行手册](references/羲和模式运行手册.md)，按注入的协作轴（半自动 collab / 全自动 auto）与强度轴（fast/deep/extreme）编排，注入值优先于默认半自动，不因缺少文字约定切回半自动：fast 隐藏 subagent_run（不派独立子代理），deep 才开四种重手法，extreme 才开三固定职责、动态池与红队；结构化决策卡支持 2–6 个有依据候选+自定义，候选盘点按题意列、不硬凑，只有一个时用普通确认，`decision_judge` 仍只收恰好 3 个；证据门禁不随档位变化。不自行切档，不改宿主配置。

先完成题目契约：逐问要求、输入/输出、实体、单位、时钟、空间范围、约束、跨问接口、外部资料角色、可识别性与失败条件。附件只读；下载完成、格式可解、目标区域有有效值、科学语义可用、事前可获得，分别验收。实验保留代码、输入清单/哈希、运行环境、参数、随机性、原始结果、错误日志和图表来源。选择题型相称的检验；运行成功、独立复算、模型有效、人工核验、提交成功是不同状态。

用户提供博主答案、经验帖、截图或其他比赛仓库时，按 [第三方主张取舍](references/third-party-claims.md) 将其转成待核问题；不采纳现成数字、排名、阈值或格式作为本题结论。实际清洗、编码、插补、特征和制图时读 [预处理与图形](references/preprocess-and-figures.md)，按目标及反例选择，不机械执行方法清单。简单可信基线优先，新增算法/特征/图表须说明解决的缺口及验证代价。正式选图、组合图或美化已有图时，再读 [竞赛图表选型与视觉升级](references/竞赛图表选型与视觉升级.md)，格式按本届赛道要求。

## 做题、写作和极致模式

优先交出能回答每问的可运行基线，再对高影响假设做反例、替代口径与公平对照。无真实灾害标签时，不能把背景时段分类 AUC 称灾害预测能力；天气产品、代理标签、模拟轨迹与真实独立事件须分母分列。前问输出变更时，识别受影响的后问和论文主张，只重跑受影响链。遇到材料不足，给出可计算的条件支路、不可识别的范围与要补的数据，避免把条件实验写成实证校准。

独立复算和 `extreme` 档按 [复算与极致验收](references/replication-extreme.md)：复算实现先锁题目与原始输入，隔离本文结果与正文；逐项写同口径对照、依赖、偏差和成因。分歧涉及结构、口径或结论时，回写正文、摘要及局限；“误差区间”不能随意用一个百分比包住不同定义的估计量。子代理受限额、掉线或通道故障时，留真实状态并恢复主线，不能把未返回报告计作通过。

论文与交付以规则档为准。正文每个关键数值都能追到原精度结果键；显示值的舍入不参与下游计算。编译通过后核实际 PDF 页码、目录、引用、字体/图件、匿名性、附录源码和支撑包清单。AI 参与和队员人工采纳分别记录，未获队员确认不得代填。提交包可生成和检查；未见提交回执不得称已提交。

写作与终审时读 [表达自然与AI痕迹检查](references/表达自然与AI痕迹检查.md)：按"先证据后修辞"逐段诊断模板腔与防御性措辞，只改表达，不动数值、口径与主张。

新建2026初赛稿件可从 [独立论文骨架](assets/paper-2026.tex) 开始；先核本届规则，保留已有稿件。它不是已完成的参赛论文。羲和用 `contest_rules` 登记已读取的来源和条款，再 `paper_build` 按当前规则审计；未知规则先做可验证的本地工作，交付前补核。Codex 等其他宿主用项目记录落实同等核查，不伪造专用工具执行。

## 国赛标杆七条补强（2026-11-24 数维杯双组复盘沉淀）
来源：2026 国赛 A 题成品审计 + 数维杯 C 题两个独立智能体解答对照 + 7 篇官方展示论文跨文剖析；与当届 MathorCup 官方规则冲突时以官方规则为准并记录依据。

- **机理检验一翼**：每问除独立复算/统计重放外，至少一项机理级检验——量纲与单位标定（不得长期记为"U"）、收敛性加密、双方法对照、守恒或收支残差，按题型选适用者。数值复现通过不等于机理正确；关联不得写成因果；靠放宽资源或钻规则边界得到的达标数字必须附合理性讨论与敏感性。
- **针对性参考文献**：至少 3 条与实际采用的解法、参数或数据来源直接对应，含近五年或赛题相关实证文献；禁止全列表只堆经典老文献。题给材料引用边界仍按规则档执行。
- **图题与图文衔接**：正文先说明图的用途，再解释它支持的判断。图注写清对象、条件和必要统计口径；关键数值或方向性结论确实有助于读图时，可写入图题。导出依当届要求，优先矢量并按需配高分辨率位图；全文统一字号、配色并检查灰度和色觉可辨性。
- **主张—证据映射+双盲终审**：在"正文每个关键数值追到原精度结果键"基础上，钉到具体结果文件、日志与随机种子；有真实 subagent 时派发互不通气的 R1（只读论文）/R2（只读代码与结果）交叉核对数值与方法主张。自查报告全量披露编译与校验警告（含 Underfull 类低危项），不得避重就轻；无独立审阅能力时如实标注未执行。
- **文码一致与信息因果审计（R5）**：附录代码须真实实现正文主张的方法（防中位数冒充 LightGBM、防硬编码演示骨架）；滚动/实时决策逐时点审计 t_avail≤t_dec，禁用未来真实值。实证：2026 展示 C084/B020/C119。
- **展示精度不超过误差量级（R6）**：报告口径有效位数不超过网格/步长/样本收敛差量级；显示舍入与达标判据分开。实证：A020 毫秒级 vs 0.25 s 网格差。
- **诚实收束（R7）**：边际改进给置信区间（CI 含 0 直书）；启发式不称全局最优；局限与推广逐条对应；优化问声明目标口径与代价。实证：C119/C084/B091/B141 正面。

## 摘要命中评分要点与过程化思维（2026-11-24 用户洞察）
- **摘要前置硬步骤（写摘要章节时强制执行，先于摘要动笔——摘要通常在正文与结果定稿后写；摘要命中评分要点优先于图美观）**：评委先读摘要判断是否读懂题，一句踩中评分要点比一张漂亮流程图更值钱（实例：某入选论文流程图被吐槽线条随意、框不好看，仍因摘要第二句命中官方"利用同星期工作日与双休日差异做实时预测"要点——全国寥寥无几有人做——而入选）。动笔前依次做：①读当届官方讲评/评分要点（资料库 `官方评阅与点评/官方讲评2024-2026/要点提取_*.md` 与各题讲评；当届未发布则读同题往年讲评＋题面"建议/提示"句，标注年份局限）；②提炼 3–5 条评分要点/官方建议洞察清单，逐条标"本文是否做到、证据在哪一问"；③锁定"全国寥寥无几有人做"的差异化洞察，确认本文真做了且有结果支撑；④摘要显眼位置（通常首段；句序随题目自然结构，不绑死前两句）必须命中至少一条与本文结果吻合的核心要点，再展开"问题—方法—数值"。命中靠对题意的深刻理解与真实结果，规则只保证可见性与证据、不替代理解；未做到就如实写，不为命中虚构——此句是写作时的内部判据和向用户交付时的说明，不写入论文正文。无官方讲评可读取时从题面建议句＋数据结构自拟候选洞察，标"自拟要点（待官方核验）"，不伪称官方口径。整体视觉舒适（字号配色统一、留白得当）服务于读懂，不凌驾于洞察与结果正确性。
- **选合适算法而非最新算法**：线性问题不上深度学习，机理清晰用机理模型；算法适配题意与数据，不为炫技堆新模型。官方"鼓励创造性"指服务题意的洞察，不是方法新颖度。
- **过程化思维（2027 趋势）**：未来评阅可能要求作品体现思维过程——参数如何确定、假设如何取舍、为何选此模型而非彼模型。把关键参数的来源/标定/敏感性推理写进正文，不只给结果；这是 AI 当前不擅长、人主导增值处。
- **正文页数红线**：正文不超过 30 页（附录不限；分别统计摘要/正文/附录，不用 PDF 总页数替代正文页数）是红线，超页严肃处理，以当届官方格式规范核验为准。美观服从页数与匿名规范，不为版面挤占实质。

## 妈妈杯摘要写法（内部质量目标，非官方评分条款；格式以规则档为准）
摘要与题目、关键词同载第一页（规则档），原则上一页、匿名、独立可读。妈妈杯是大数据竞赛，摘要必须既有洞察又有数据证据，硬要求：
1. **逐问三要素**：每问"问题—方法—关键数值结果"齐全，数值密度高；核心结果（指标、规模、成本、精度）入摘要，不只写方法名。无数值就补实验或写诚实定性结论，工作占位符不进摘要。
2. **显眼位置命中评分要点**：先执行上文「摘要前置硬步骤」，把"全国寥寥无几有人做"的差异化洞察放在摘要显眼位置（通常首段，可第二句也可由其他自然结构承载），再展开各问；洞察须由本文结果支撑，不为命中虚构。
3. **大数据要素点到**：数据规模/来源与关键预处理、模型/算法、验证指标（带数值与口径）、应用/业务价值——让评委一眼看出"用了什么数据、做了什么、得到什么、有何用"。
4. **口径诚实**：摘要数值与正文/台账同源（双口径），合计可加和；条件实验不写成实证校准，背景时段分类 AUC 不称灾害预测能力，分母/独立性/区间性质交代清楚；边际改进不夸大（CI 含 0 直书）。
5. **关键词 3–5 个**：指向具体对象与方法（如"LightGBM 分位数回归""滚动 MPC"），不堆空泛词。
6. **独立可读**：脱离正文能交代真实成果与边界；末尾只写已实现价值，不写教程、空泛背景或正文不存在的创新/数字。
摘要字数/页数/关键词数以当届官方 PDF 核验为准；本节是质量目标，与官方条款冲突时以官方为准并记录依据。

运行在 Codex、羲和、DeepSeek 或其他宿主时，读 [宿主路由与断点恢复](references/runtime.md)；羲和宿主另读 [羲和适配](references/羲和适配.md)（角色模型、子智能体、技能槽位与门禁工具映射）与 [羲和模式运行手册](references/羲和模式运行手册.md)（三档 × 半自动/全自动、成本纪律与失败降级）；只有实际暴露且能调用的工具才算可用。模型和渠道以本次会话真实配置与探针为准，不把某次成功的型号、代理地址或回退链写成通用默认。

最终报告按本轮范围列：权威产物路径、实际执行和验证证据、未覆盖的事项、人工核验/提交状态。无需把未请求的赛程模板强加给局部修复。
