# 2026 A/B/C 蒸馏算法决策卡

核对：2026-11-17。已读官方 A/B/C 题面，以及 A133、A020（官网标题A20）、B091、B141、B020、C119、C084 各自摘要页。未完整审计 7 篇源码或复算论文结果。以下为本库整理的可选算法设计，不是现成求解代码、官方标准答案或固定评审表。

## A 类机制：热质传递 / 变物性 / 收缩域

输入先核几何、材料定义、物性、边界时程与目标精度；输出是状态场、达标事件或参数解释。基线可以是常物性、固定域或可解析简化；再选择 FVM/FDM 等离散和 Picard/Newton、BDF 等适当推进。只有题目需要时才增加移动域和阈值事件。验收关注守恒、轴心和表面边界、加密/步长变化、全域终点与输出坐标。圆柱不自动使用球体权重；容差、节点数和时间步由本题误差预算确定。

## B 类机制：测向几何 / 部分观测 / 搜索清除

输入包括角度误差、接收条件、运动和操作成本；输出包括可行位置集合、下一动作及停止理由。基线可从角域半平面交集、凸多边形几何和简单覆盖调度开始；按规模再比较主动选点、最小包围圆、动态规划、整数规划或滚动局部搜索。区分区域直径与覆盖半径、未接收与确定不存在、网格内检查与连续保证。真实模拟器日志用于本次成绩，历史论文统计不能替代本系统运行。

## C 类机制：时间预测 / 储能 / 风险决策

输入包括带发布时间的负载/光伏/电价、设备参数和结算规则；输出是可执行计划、后续调整、费用与风险。先做合法信息集上的简单预测和确定性储能优化，再按需要比较分位决策、场景随机规划、稳健优化或 MPC。验收 SOC、能量单位、初末条件、已执行动作及全部结算项。预测与决策指标分别评价；不能使用未来真实数据调参或提前读取晚发布预报。
