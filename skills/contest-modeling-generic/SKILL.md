# 通用数学建模竞赛工作流

适用范围：赛事身份未识别或尚未安装赛事包；普通数学建模分析也可按任务范围使用。赛事名称、届次、赛道、初赛或决赛、题目、提交时间及格式从当届有来源的材料中确认。题面、官方规则、用户约定和第三方经验分别记录；博主答案、获奖论文、其他赛事模板不构成本题事实或当届规则。局部修复或复算沿用现有项目，不重启整题。

## 推进

1. 逐问列出目标、输入、输出、单位、时空范围、约束、评价指标和跨问接口；登记题给事实、必要假设、数据缺口和可解性。检查附件的格式、缺失、质量标志、有效时间和来源，不以文件存在或时间戳完整推定数据有效。
2. 为可解问题建立实际运行的简单基线。方法依题型选取，模型复杂度由证据和收益决定。训练、验证和事前预测所用数据按取得时间隔离；类别编码、插补、尺度变换和异常处理仅在相应样本划分内拟合。记录输入、代码版本、环境、参数、随机性和原始结果。
3. 迭代高影响假设或结构：先写比较口径与成功条件，再做公平对照。改动上游时核下游结果和论文主张。检验按问题选用约束回代、样本外误差、守恒或极限、独立复算等；明确哪些证据与主解共享数据、代码或假设。
4. 论文按题目组织逐问答案、推导、实际结果、检验和局限。摘要只提炼已完成的工作，关键数值追溯到结果文件。图表按信息增益选择，标来源和单位；文献必须实际查阅和引用，不把题面默认当外部参考文献。
5. 交付前核实当届格式、页数、目录、附录、AI 披露、附件与提交规则。编译并检查成品页面，核对代码与结果可定位、匿名要求和包内清单；生成包、人工确认和实际提交是不同状态。

本 Skill 不规定赛事时长比例、页数、目录、附件体积或 AI 声明位置。规则未知时继续可验证的本地求解，并在交付验收前补充有来源的当届规则。快速、深度、极致三档决定执行强度，不改变赛事规则。
